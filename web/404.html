Looking for a capability page?

Dossier URLs are keyed by the id the CLI uses, not the display name — an npm-backed server lives at /capability/pkg-<package>, a registry-only one at /capability/registry-<name>, with every non-alphanumeric character replaced by a dash. Searching the Index for the name is quicker than guessing the slug.

If you believe something should be measured and is not, that is a request — it is the queue we work from.
