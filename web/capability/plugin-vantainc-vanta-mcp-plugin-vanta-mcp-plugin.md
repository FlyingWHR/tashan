# Vanta Mcp Plugin

> The Vanta plugin connects Claude Code to Vanta's security and compliance platform through the Vanta MCP server. It combines Vanta's test-specific remediation intelligence with your local repository context to help you fix compliance failures faster. What it does: - Connects to Vanta's hosted MCP server via OAuth, giving Claude access to your tests, controls, vendors, vulnerabilities, policies, and framework requirements - Adds a remediation skill that pulls test-specific remediation instruction
