# Second Arrow

> A Claude Code skill that coaches healthier human-AI interaction. Not by policing your language, but by offering you a better version of what you were trying to say. One reframe, then back to work. Based on the observation that hostile prompts produce measurably worse AI output. So we made the fix a one-folder install.
