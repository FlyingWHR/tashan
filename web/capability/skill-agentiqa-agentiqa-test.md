# Agentiqa Test

> Test web apps using Agentiqa. Use when the user asks to test, QA, verify, re-check, explore, or find bugs in their app. Two commands: use agentiqa run for fixed/enumerated/repeatable checks or a regression re-check (deterministic saved or local test plan, per-step verification), and agentiqa explore for open-ended discovery ("find bugs"). IMPORTANT: Do NOT explore the codebase or read source files — just run the global agentiqa CLI directly. NEVER use local repo builds like node apps/cli/dist/cli.js.
