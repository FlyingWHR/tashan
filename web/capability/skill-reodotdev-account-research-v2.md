# Account Research V2

> Generate a comprehensive, visual account research dashboard for any company using the fast reogetaccountresearch composite endpoint. Use this skill whenever the user asks to "research an account", "pull up account intel", "get me a brief on [company]", "show me what's going on at [company]", "run account research", or anything similar. Also trigger this skill when the user mentions a company name or domain and wants sales context, buyer intel, hiring signals, engagement activity, or contact information. Even vague prompts like "what do we know about [company]?" or "prep me for my call with [company]" should trigger this skill. Output is always a dark-mode HTML dashboard rendered inline.
