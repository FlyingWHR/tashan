# Critical Thinking Tools

> Critical Thinking Tools is a science-backed Claude Code plugin from Cognitive Bias Lab that helps users reason more clearly about decisions, beliefs, plans, forecasts, and disagreements. It provides structured thinking workflows based on research in psychology, decision science, forecasting, intelligence analysis, and debiasing. The plugin includes 12 practical tools: devil’s advocate review, pre-mortem analysis, outside-view forecasting, competing hypotheses, consider-the-opposite, steelmannin
