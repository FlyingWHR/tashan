# Slide Revive

> Rebuild NotebookLM slide PDFs as fully editable PPTX files using Vision AI. NotebookLM exports each slide as a flat image, making text and shapes impossible to edit. slide-revive extracts each page, analyzes it with Claude Vision, reconstructs the slide structure with native text boxes, tables, and shapes, and generates a polished .pptx alongside an instant .html preview — all in one command. No external API key required. Supports macOS and Windows.
