reminders-for-macos

plugin:high5-ventures/apple-reminders-for-claude/reminders-for-macos · plugin

Fast, native macOS Apple Reminders integration via Apple's EventKit framework. Thirteen MCP tools cover the full lifecycle: list, search, today/overdue/scheduled queries, and create/update/complete/delete. Signed and notarized Swift binary, 10-200x faster than AppleScript. 100% local at runtime, no telemetry.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
