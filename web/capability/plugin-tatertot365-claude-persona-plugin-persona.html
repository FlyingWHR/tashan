Persona

plugin

The user can inject experts into their Claude Code session. It provides the programmed experts with specific priorities, communication styles, and domain knowledge to help. Each persona has references and skills for improved capabilities and the user can even delegate tasks to personas which will spawn subagents to complete the task with their domain expertise.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
