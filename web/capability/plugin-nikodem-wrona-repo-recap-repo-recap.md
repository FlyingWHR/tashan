# Repo Recap

> Generate structured summaries of your git repository activity with a single slash command. See who did what, which areas changed, and the most active files — organized by contributor, directory, and file churn. When the GitHub CLI (gh) is installed, recaps are automatically enriched with pull request titles, descriptions, labels, review status, and linked issues.
