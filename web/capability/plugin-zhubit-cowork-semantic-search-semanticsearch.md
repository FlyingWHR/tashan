# Semanticsearch

> A fully offline semantic search tool for Claude. Index local files (PDF, DOCX, Markdown, TXT, PPTX, CSV) into a vector database and search them using natural language. Uses hybrid search combining vector similarity with full-text keyword matching for accurate retrieval. Supports incremental indexing, 50+ languages, and runs entirely on your machine — no API keys, no data leaves your device.
