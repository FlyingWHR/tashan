# Claude Meta Skills

> claude-meta-skills is a technical-preview reliability hook suite for Claude Code. It adds five local hook checks that help Claude catch common agent failure modes while working in a repository: stale Edit context, protected-path modifications, missing or empty writes, failing tests at Stop, and lost recovery context before compaction. It is local-first, metadata-only in persistent logs, and intentionally not a Bash sandbox, broad workflow framework, hosted telemetry tool, or production-proven sa
