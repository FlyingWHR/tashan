# Claude Telegram Voice Control

> Telegram channel with local voice transcription via whisper.cpp. Voice messages are automatically transcribed on-device using the Whisper medium model before being forwarded to Claude — no external APIs, no data leaves the machine. Cross-platform auto-install of whisper-cpp and ffmpeg. Gracefully degrades to standard behavior when dependencies are unavailable.
