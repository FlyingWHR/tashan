# Playwright Pro

> Playwright Pro turns your AI coding agent into a senior test automation engineer. Instead of generating tutorial-quality tests with brittle CSS selectors, Playwright Pro enforces battle-tested patterns from production test suites: role-based locators, web-first assertions, proper fixture architecture, and isolated test design. It doesn't reinvent Claude Code — it orchestrates it. /pw:generate uses the built-in Explore subagent for codebase analysis. /pw:migrate delegates to /batch for parallel
