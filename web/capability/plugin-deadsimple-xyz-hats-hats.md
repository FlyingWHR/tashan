# Hats

> Your personal AI dev team. Five specialized roles — Manager, Designer, CTO, QA, and Developer — each with isolated context and permissions. The Manager writes Gherkin specs, then each role takes over: Designer creates mockups, CTO picks the stack, QA writes tests from requirements (not implementation), and Developer builds the code. Role separation prevents shared blind spots — the QA can't see Developer instructions and vice versa.
