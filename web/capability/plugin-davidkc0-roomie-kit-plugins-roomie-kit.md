# Roomie Kit

> Roomie Kit helps developers bootstrap, customize, and validate open-source realtime apps built with virtual rooms, livestreaming, video chat, games, Supabase, Agora, Vercel, and Capacitor. The plugin connects Claude Code to the Roomie Kit CLI so paid Roomie Kit Cloud users can log in, create a starter project, run setup checks, customize branding/assets, and troubleshoot deployments from inside their editor.
