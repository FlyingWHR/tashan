# Eterdis Strategy Skills

> Open strategy frameworks for AI agents — 11 skills that turn any LLM into a strategy thinking partner. Each skill is a structured SKILL.md prompt that guides the AI through a proven strategic framework (VRIO, Wardley Mapping, Playing to Win, Pre-Mortem, and more). Built on 20 years of consulting practice. Three modes per skill: Diagnostic (deep session), Review (periodic check), and Alert Triggers (early warnings). All skills share a company-context.md file for accumulated strategic intelligence
