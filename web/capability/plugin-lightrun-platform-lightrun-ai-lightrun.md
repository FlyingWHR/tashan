# Lightrun

> Lightrun's runtime investigation toolkit for Claude Code. Guides deterministic, evidence-first debugging of live applications by capturing real production behavior — variable state, stack traces, and execution flow — without redeploys or service restarts. Includes a mandatory preflight check that grounds investigations in actual runtime evidence, plus a blocker-aware handoff format that produces structured, reproducible debugging reports for engineering teams.
