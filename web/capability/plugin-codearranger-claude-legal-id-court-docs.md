# ID Court Docs

> Idaho court documents: I.R.C.P. 2 / 10 formatting; Ada (Fourth Judicial District / Boise) + Bonneville (Seventh Judicial District / Idaho Falls) District Courts + Magistrate Division + county roll-up; consumer-debt and family-law bundles. Idaho quirks: time computation lives in I.R.C.P. 2.2 (Rule 6 reserved), a separate Idaho Rules of Family Law Procedure set, and community property. Full detail in the plugin README.
