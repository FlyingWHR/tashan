# Vibe Keystone

> Vibe Keystone bootstraps a CLAUDE.md for any repository — the load-bearing structural file every agent decision in that repo will rest on. Unlike a generic template, Keystone interviews the user for org / decision surface / voice rules / persona before drafting, so the produced file reflects YOUR conventions, not 626Labs defaults baked in.
