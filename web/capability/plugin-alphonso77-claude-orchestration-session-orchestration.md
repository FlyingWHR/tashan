# Session Orchestration

> Coordinate parallel Claude Code sessions for complex features. Alpha plans the effort and assigns tasks. Beta and Gamma build in separate terminals. Delta verifies. Each session reads its task from a shared coordination file — no copy-pasting prompts between terminals. Keeps the human close to the effort during vibe coding. Alpha remains free during the build for brainstorming, research, questions, pivots, and architectural code reviews. Built-in wrap-up flow updates CLAUDE.md at the close of ea
