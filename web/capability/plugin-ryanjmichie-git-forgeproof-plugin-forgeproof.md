# Forgeproof

> ForgeProof turns GitHub issues into working, AI-generated code backed by a tamper-evident receipt. Claude Code reads the issue, extracts requirements, writes code and tests, then seals everything into a signed .rpack provenance bundle. The bundle proves what was done, why, and that nothing was altered after signing — a cryptographic receipt that travels with the code.
