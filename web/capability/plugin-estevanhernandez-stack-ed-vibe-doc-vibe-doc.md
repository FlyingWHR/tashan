# Vibe Doc

> Vibe Doc is an AI-powered documentation gap analyzer for any codebase. It scans your project's artifacts, classifies the project type (web app, API, data pipeline, Claude Code plugin, etc.), measures coverage against a tier-appropriate documentation matrix, and either generates the missing docs from your existing artifacts or hands you a ranked list of gaps to close.
