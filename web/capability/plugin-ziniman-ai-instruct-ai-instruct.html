AI Instruct

plugin

Five practical skills covering the domains developers most often Google when shipping a website. Each skill auto-loads only when relevant to the task: Web Accessibility on UI work, SEO/LLMO before launch, Core Web Vitals on performance issues, AWS SPA deploy on Amplify/CDK work, and Google Analytics 4 on tracking setup. Originally distributed as standalone markdown guides for any AI tool (also available via npx ai-instruct init); now packaged as a single Claude Code plugin for one-command instal

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
