# Cookiy

> Cookiy is a Claude Code plugin for end-to-end user research. It provides skills to design research plans, screening questionnaires, and discussion guides; analyze and synthesize raw interview notes or transcripts into evidence-backed reports; and—when using Cookiy AI—run AI-moderated qualitative interviews and quantitative surveys with recruitment and reporting. Use it whenever the task involves user research, customer discovery, interview guides, surveys, or research synthesis.
