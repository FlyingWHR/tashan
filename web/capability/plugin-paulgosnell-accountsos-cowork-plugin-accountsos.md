# Accountsos

> AI-native UK accounting for limited companies and sole traders. Track transactions, manage VAT, monitor HMRC deadlines, log expenses, and handle invoices through natural language. Auto-fires UK tax knowledge skills (Corporation Tax, VAT, MTD, BADR, capital allowances) verified for the 2026/27 tax year. Pairs with your AccountsOS account via API key — connects to your live books so Claude can read balances, create transactions, check deadlines and answer UK tax questions with gov.uk source citati
