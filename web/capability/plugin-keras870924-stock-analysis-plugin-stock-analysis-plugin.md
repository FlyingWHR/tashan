# Stock Analysis Plugin

> Suggested Value: A two-layer stock analysis framework for US and Taiwan equities. Layer 1 evaluates fundamentals (business model, moat scoring, financial health, valuation). Layer 2 applies technical analysis (trend direction using clock positions, chip distribution for support/resistance, risk management). Outputs bilingual (English/Chinese) structured reports with actionable verdicts.
