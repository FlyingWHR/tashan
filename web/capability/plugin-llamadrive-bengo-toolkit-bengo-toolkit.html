bengo-toolkit

plugin:llamadrive/bengo-toolkit/bengo-toolkit · plugin

Japanese law firm plugin for Claude Code — court template filling, family tree generation (相続関係説明図), legal document proofreading, lawsuit analysis, e-Gov law search, and deterministic legal calculators (traffic damages, child support, debt recalc, overtime, iryubun, property division, inheritance). Ships HMAC-chainedtamper-evident local audit logs (append-only JSONL with optional HMAC keying) recording which documents were processed, when, by which skill — without storing document contents. 日本の
