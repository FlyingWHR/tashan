claude-english-buddy

plugin:xiaolai/claude-english-buddy-for-claude/claude-english-buddy · plugin

A UserPromptSubmit hook that helps non-native English speakers improve while using Claude Code. Three modes dispatch automatically based on what you type: (1) correct — if your English prompt has errors, the hook fixes them and shows a per-line wrong → right (reason) diff so you learn the rule, not just the fix; (2) translate — if the input is non-English (Chinese, Japanese, Spanish, etc.), it's translated into natural English while preserving technical terms, file paths, and tool names; (3) r

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
