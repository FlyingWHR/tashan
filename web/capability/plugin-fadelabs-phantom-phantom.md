# Phantom

> AI audio engineering system that turns Claude into a professional mix and mastering engineer. Point it at stems or a full mix, give it a reference track you want to sound like, and it handles the rest: diagnostics, session setup, mixing, effects, and mastering in Reaper. Backed by real-time spectral, loudness, dynamics, stereo, and phase analysis via the Phantom MCP server. 5 domain expert skills work together as a complete audio production pipeline: analyze first, set up the DAW, mix with me
