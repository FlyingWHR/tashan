# Project Pilot

> Project Pilot is a Claude Code plugin that gives Claude a persistent memory layer for your project. It captures your architecture decisions, coding conventions, and current progress into a .pilot/ folder. Every new session starts with full context — no re-explaining, no re-discovering. It works silently in the background. You code normally. Project Pilot tracks what changes, updates its knowledge, and warns you before you accidentally break something important.
