# Design Is Code

> Transform UML sequence diagrams and decision tables into Java tests and code. The DisC methodology applies London-school TDD to AI code generation: every design arrow becomes a verify() test and every decision-table row becomes one leaf test, so mockist tests pin call structure, order, and arguments — leaving no room for AI interpretation. Phase 1 generates tests from the design; Phase 2 derives the implementation from the tests alone. Currently supports Java + Spring Boot with PlantUML sequence
