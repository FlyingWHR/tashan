# Gst Invoice Generator India

> Generate fully GST-compliant Indian tax invoices in 30 seconds. The plugin auto-detects whether to charge CGST+SGST or IGST based on the seller's GSTIN state code and the place of supply, suggests the right HSN/SAC code for each line item, converts amounts to Indian-numbering words (Lakh/Crore), and produces a clean printable invoice in chat.
