# Vibeguard

> Security auditor and hardener for vibe-coded projects. 170+ vulnerability checks across 24 categories including injection, XSS, auth bypass, IDOR, Supabase RLS, prompt injection, exposed secrets, rate limiting, CORS, and auth provider misconfigs. Three commands: /vibeguard:audit (scan and report), /vibeguard:fix (patch findings), /vibeguard:harden (add security infrastructure). Includes a pre-commit hook that blocks git commits containing hardcoded secrets.
