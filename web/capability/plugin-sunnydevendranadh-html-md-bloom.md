# Bloom

> Sticky session mode that turns flat markdown into rich, self-contained .html artifacts. Activate with /bloom once and every substantial output for the rest of the session — status reports, PR reviews, design docs, comparisons, plans, diagrams, slide decks, postmortems, triage boards, flag and prompt editors — becomes a single browsable .html file with semantic HTML5, inline CSS/JS, and zero external dependencies. Reserved files like README.md, CLAUDE.md, and AGENTS.md keep their canonical markdo
