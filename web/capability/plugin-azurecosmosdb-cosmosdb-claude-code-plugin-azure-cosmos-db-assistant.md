# Azure Cosmos DB Assistant

> An expert assistant for Azure Cosmos DB that provides guidance on data modeling, query optimization, performance tuning, and best practices. The plugin works out of the box with no external configuration required. It includes a specialized agent and curated skills to help developers design, build, and troubleshoot Cosmos DB applications efficiently. Optional integration with the Azure Cosmos DB MCP Toolkit is available for advanced scenarios, but is not required for core functionality.
