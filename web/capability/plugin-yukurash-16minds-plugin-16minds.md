# 16minds

> 16-minds summons agents modeled on 16 distinct personality types — each with its own values, thinking patterns, and tone — to debate, review, or advise on any topic. Each personality is written directly into an independent prompt, so outputs carry visibly different voices instead of the averaged answer a single agent tends to produce. Three commands cover the range: - /mind <type — a single type's opinion - /pair <a <b — a two-type debate (open → rebut → reply / synthesize) - /minds —
