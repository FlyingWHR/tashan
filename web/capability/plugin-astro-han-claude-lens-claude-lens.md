# Claude Lens

> Fast statusline for Claude Code with pace tracking. Shows quota remaining and whether you're ahead or behind ideal consumption pace -- green means headroom, red means slow down. Also displays context usage with trend arrows, git status, active tools, subagent/todo progress, and session speed. Pure Bash + jq, renders in ~50ms, O(1) transcript parsing, zero config required.
