gemini-for-claude

plugin:philipvanlewis/gemini-for-claude/gemini-for-claude · plugin ✓ Google · official

Bridge Claude Code to Google's Gemini CLI. Mirrors the pattern of the official Codex plugin but for Google's AI stack. Adds 9 slash commands under /gemini: for code review, adversarial security review with CVE search, web-grounded research via Google Search (capability Codex lacks), task delegation with 1M-token context, image generation via nanobanana, and background job management. Supports Google OAuth (free tier), API key, and Vertex AI auth. Zero npm dependencies — one auditable Node.js ESM

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
