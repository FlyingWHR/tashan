AI Slop

plugin

Catch AI slop and apply writing conventions to any prose — drafting Markdown, documentation, or a blog post. Editing .tex files adds the empirical software engineering paper rules plus LaTeX checks (BibTeX, reference verification) automatically; --scientific applies the paper rules to a non-LaTeX manuscript. Combines these with the community-maintained tropes.fyi catalog of general AI writing patterns.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
