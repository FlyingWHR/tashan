# Larch

> Larch is a multi-agent workflow automation plugin for Claude Code that orchestrates the full software development lifecycle — from design through merge — using collaborative AI agents. It provides six slash commands (/design, /implement, /review, /research, /loop-review, /alias) that coordinate up to 5 parallel agents (Claude subagents + Codex + Cursor) with a voting-based review system to adjudicate findings.
