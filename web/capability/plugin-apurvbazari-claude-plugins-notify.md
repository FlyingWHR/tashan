# Notify

> System notifications for Claude Code. Get notified when tasks complete, Claude needs your input, or subagents finish work. Supports macOS (terminal-notifier) and Linux (notify-send). Features include: - Contextual messages extracted from Claude's actual response - Repo and branch context in notification subtitles - Duration filtering to suppress notifications for fast responses - Per-event customization (sound, app activation, enable/disable) - Global or per-project install scopes - Interactive
