# Clawcode

> ClawCode is an open-source plugin that turns otherwise stateless sessions into persistent agents. It adds identity, personality, long-term memory, lifecycle hooks, memory consolidation (“dreaming”), voice support, web hooks, messaging integrations, and a one-way import path from OpenClaw. The goal is to make Claude Code feel less like a fresh assistant on every launch and more like a continuous agent that remembers context, adapts to the user, and maintains a stable sense of self across sessions
