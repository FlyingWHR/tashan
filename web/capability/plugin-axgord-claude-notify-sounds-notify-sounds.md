# Notify Sounds

> Plays system sounds in Claude Code when a task finishes or when permission is needed, so you don't have to keep watching the terminal. Cross-platform: macOS (afplay), Linux (PulseAudio/PipeWire), Windows (PowerShell SoundPlayer), with terminal-bell fallback. Sub-agent stops are skipped to avoid noise during multi-agent workflows.
