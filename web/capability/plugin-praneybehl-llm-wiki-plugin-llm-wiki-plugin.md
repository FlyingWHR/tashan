# LLM Wiki Plugin

> Build and maintain an LLM-curated personal knowledge base in your project. Implements Andrej Karpathy's LLM Wiki pattern with sharded indexes, atomic pages, BM25 search, and a structural lint script - designed to scale to thousands of pages without becoming a context bottleneck.
