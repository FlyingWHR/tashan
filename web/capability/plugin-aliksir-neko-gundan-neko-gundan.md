# Neko Gundan

> Multi-agent orchestration framework for Claude Code. Organizes Claude into a hierarchical cat team — Oyakata-neko (General/Opus) plans strategy, Shigoto-neko (Manager/Sonnet) breaks down tasks, and Genba-neko (Worker/Sonnet) executes in parallel. Features auto-scaling from solo to battalion based on task complexity, quality gates with structured review protocols, and bidirectional feedback loops.
