# Rpm Relentless Product Manager

> rpm persists project state across Claude Code sessions and prevents guidance and documentation drift. It uses hooks to automate most of the effort, and stores everything in human readable files. User initiated /audit command catches drift in three tiers: mechanical scan, scored subagent review, and full project review. All implemented with zero dependencies and all bash.
