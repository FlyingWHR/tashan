# Bengo Toolkit

> Japanese law firm plugin for Claude Code — court template filling, family tree generation (相続関係説明図), legal document proofreading, lawsuit analysis, e-Gov law search, and deterministic legal calculators (traffic damages, child support, debt recalc, overtime, iryubun, property division, inheritance). Ships HMAC-chained, append-only local audit logs (tamper-evident records of which documents were processed, when, and by which skill — without storing document contents). 日本の法律事務所向け Claude Code プラグイン
