# Agenticmail

> Give every Claude Code subagent its own real email address and phone number, all self hosted on the user's machine. AgenticMail runs a local mail server (Stalwart in a Colima or Docker container) so each agent has a working <name@localhost inbox, an identity, an API key, and a persona. When a teammate is CC'd on an email they wake up as a Claude Code subagent under your existing Claude OAuth, read the full thread, decide if it is their turn, and either reply to all or stay silent.
