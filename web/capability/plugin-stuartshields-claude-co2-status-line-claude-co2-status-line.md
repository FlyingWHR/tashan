# Claude Co2 Status Line

> Adds a status line that estimates the environmental cost of your Claude Code session in real time. Shows cumulative energy usage (Wh), CO2 emissions (g), water consumption (ml), and token count — updated after every interaction. Based on published research from Epoch AI, with all formulas and sources documented. Supports wrapping existing statuslines and opt-in all-time tracking.
