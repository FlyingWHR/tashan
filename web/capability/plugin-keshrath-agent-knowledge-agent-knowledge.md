# Agent Knowledge

> Cross-session memory for AI coding agents. A git-synced Markdown knowledge base with hybrid semantic + TF-IDF search, typed knowledge graph (11 edge types with directed BFS traversal), confidence/decay scoring, and automatic session distillation with secrets scrubbing. Reads session history from Claude Code, Cursor, and OpenCode.
