# Sindri

> Sindri turns a one-line goal like "reduce bundlebytes by 15%" into an autonomous, overnight experiment loop. It proposes candidates,applies them in fresh subagent contexts, runs your benchmark, keeps the wins as git commits, reverts the losses, and opens a PR with a human-readable log. One commit per kept experiment. Git is the audit log.
