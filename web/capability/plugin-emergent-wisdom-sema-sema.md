# Sema

> Sema adds a content-addressed vocabulary of 452 cognitive patterns to Claude. Each pattern has a handle like StateLock5602 — a SHA-256 hash of its definition — so two agents using the same handle are provably talking about the same thing. Any divergence in meaning produces a different hash, making silent misalignment impossible. Key features: - semasearch — semantic + keyword search across the pattern library • semaresolve — full definition, mechanism, invariants, and dependency graph for a
