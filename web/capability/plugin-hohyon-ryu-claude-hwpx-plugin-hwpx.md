# Hwpx

> Read, write, and convert HWP/HWPX (한글) documents — South Korea's dominant document format. Extract text, math equations, images, and tables from HWP/HWPX files. Generate HWPX documents programmatically with B4/A4 layouts, equations, and images. Convert between HWP/HWPX and Markdown bidirectionally. Includes HWP equation script syntax knowledge, HWPX XML schema reference, and ready-to-run Python converter scripts.
