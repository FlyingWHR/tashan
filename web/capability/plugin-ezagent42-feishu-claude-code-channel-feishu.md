# Feishu

> Feishu (Lark) channel for Claude Code — messaging bridge that connects a Feishu bot to Claude Code via MCP server. Receives messages through Feishu WebSocket long connection (no public IP required), forwards them to Claude, and provides tools for replying, reacting, editing messages, fetching history, and downloading attachments. Built-in access control with pairing flow, allowlists, and per-group policies.
