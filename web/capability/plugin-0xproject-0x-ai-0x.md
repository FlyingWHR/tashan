# 0x

> Guide developers through swapping ERC-20 tokens using the 0x API. Covers standard swaps via AllowanceHolder and Permit2 as well as gasless swaps across 20+ EVM chains — walking through price quotes, approvals, EIP-712 signing, and transaction submission. Also helps integrate 0x swaps directly into your app with code samples.
