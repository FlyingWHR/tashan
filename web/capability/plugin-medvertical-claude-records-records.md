# Records

> Records is a local-first FHIR validation and data-quality workflow plugin for Claude Code. It helps FHIR developers, IG authors, and AI agents validate FHIR JSON, explain OperationOutcome issues, map generated SUSHI/FSH artifacts back to source, derive project quality rules, and add CI validation while preserving privacy boundaries. It uses local or user-configured runtimes first and does not send patient data to external services by default.
