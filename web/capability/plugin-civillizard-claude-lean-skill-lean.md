# Lean

> Plan tasks with optimal model routing to minimize token usage. Breaks work into steps, assigns each the right model (Haiku/Sonnet/Opus), adds quality gates between stages, persists the plan to file, and reports savings after execution. Includes a companion hook for always-on model suggestions. Use /lean before complex tasks.
