# Claude Prompt Library

> Save, search, load and manage reusable prompts across projects. Build a personal prompt library that persists across sessions and works in any project. Key features: - Save prompts with description, category and tags via /prompt save - Load prompts instantly via /prompt:<name autocomplete - Search by name, tag, category or content - Edit prompts in-place with automatic metadata sync - Cross-platform: bash (macOS/Linux) and PowerShell (Windows) - Persistent storage that survives plugin updates
