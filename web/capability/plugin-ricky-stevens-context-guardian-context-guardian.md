# Context Guardian

> Automatic context window monitoring and smart compaction for Claude Code. Zero dependencies. Context Guardian (cg) watches your context window usage in real time via a statusline and provides on-demand compaction tools. When usage crosses a configurable threshold, the statusline turns red and recommends compaction - preserving your work and keeping Claude sharp.
