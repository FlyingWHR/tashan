# Memoriant Test Coverage Skill

> AST-powered test coverage analysis for Claude Code. Scans source and test directories, identifies untested functions by parsing Python abstract syntax trees, and generates pytest test skeletons automatically. Finds coverage gaps that line-based tools miss by understanding function signatures, class methods, and module structure.
