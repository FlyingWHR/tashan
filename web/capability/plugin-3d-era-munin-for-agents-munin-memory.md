# Munin Memory

> Munin for Claude Code Munin is a long-term memory system for developers. Every time you work with Claude Code, Munin remembers your context, decisions, bugs, and solutions — so you never have to repeat yourself. Munin is your project's memory companion, integrated directly into Claude Code.
