# Recipe Manager

> The Recipe Manager plugin lets you manage a personal cookbook entirely through Claude Code or Cowork. It has four main capabilities: 1. Recipe CRUD — Create, view, edit, and delete recipes. You describe a dish in natural language and it generates a structured markdown file with YAML frontmatter (ingredients, cook times, tags, dietary info, etc.) 2. Recipe Search — Find recipes by ingredient, cuisine, dietary restriction, difficulty, or any combination. Supports "what can I make with..." queries
