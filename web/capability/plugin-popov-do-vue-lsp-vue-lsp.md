# Vue Lsp

> Vue 3 LSP plugin for Claude Code. Combines vue-language-server (Volar v3) with typescript-language-server into a single LSP server, providing full TypeScript intelligence for .vue files — hover, go-to-definition, references, document symbols, call hierarchy, diagnostics, completions, and rename.
