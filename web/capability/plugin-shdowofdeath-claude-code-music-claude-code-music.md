# Claude Code Music

> Intelligent coding DJ for Claude Code. Adjusts Spotify music based on your coding mood, activity, and preferences. Includes /music commands (focus, hype, chill, debug, refactor, flow), automatic mood detection from prompts, audio TTS announcements for time and task completions, session-start auto-play, and a status line showing the current song.
