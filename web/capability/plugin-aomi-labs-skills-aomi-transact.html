Aomi Transact

plugin

Use this skill to build natural-language crypto agents, web3 assistants, trading bots, blockchain MCPs, or Claude/Cowork plugins that read and write EVM chain state. Aomi turns user prompts ("swap 1 ETH for USDC", "open a 3x GMX long", "bet $100 yes on this Polymarket question") into wallet-signed transactions on Ethereum, Base, Arbitrum, Optimism, Polygon, and Linea — generic, non-custodial, with fork-chain simulation before every signature.
