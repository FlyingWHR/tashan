stitch-to-nextjs

plugin:yshaish1/stitch-to-nextjs/stitch-to-nextjs · plugin

Convert Google Stitch designs into pixel-perfect Next.js + Tailwind CSS components. Extracts exact HTML/CSS, downloads images, maps all 29 Stitch fonts to next/font/google, preserves exact colors and spacing (never rounds to Tailwind defaults), and auto-configures the stitch-mcp server for HTML code export and screenshot validation. Supports ShadCN/UI mapping, Tailwind v3/v4, and Server Components.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
