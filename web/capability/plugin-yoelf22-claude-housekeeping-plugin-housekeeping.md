# Housekeeping

> Keep your Claude Code configuration under version control with zero friction. The /houseKeeping command detects changes to your ~/.claude directory – settings, memory files, skills, hooks – stages everything, commits with a descriptive message, and pushes to your remote. Never lose a config tweak again.
