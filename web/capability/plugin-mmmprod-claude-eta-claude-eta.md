# Claude Eta

> Task duration tracker and estimator for Claude Code. Silently times every task, classifies it, and builds a local velocity profile. After 10 tasks of the same type, injects calibrated ETAs at the start of Claude's responses using your real project data. Detects repair loops by fingerprinting error content (not just count) and intervenes before tokens are wasted. Includes a hallucinated-estimate detector that corrects Claude's time claims inline. 100% local, zero telemetry, opt-in community basel
