skillcheck-free

plugin:olgasafonova/skillcheck-free/skillcheck-free · plugin

SkillCheck Free validates Claude Code SKILL.md files against ~25 contract rules covering structure, naming, semantic consistency, and quality patterns. It catches missing frontmatter, weak or ambiguous descriptions, trigger collisions, anti-pattern formatting (prose where tables belong), naming smells, and contradictions before users encounter them. Runs locally — it's itself a SKILL.md the agent reads, with no API calls, binaries, or external services. MIT-licensed. Works in Claude Code, Claud

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
