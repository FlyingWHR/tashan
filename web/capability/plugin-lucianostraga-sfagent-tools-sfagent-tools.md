# Sfagent Tools

> AI-powered testing for Salesforce Agentforce agents. Claude reads your agent's topics, actions, and configuration, then autonomously generates and runs test conversations — probing edge cases, validating guardrails, checking topic routing — and produces a scored report with recommendations. Zero setup: uses your existing Salesforce CLI authentication. Define business rules in sfagent-config.yaml and get rule-by-rule pass/fail results. Watch every conversation in real-time via a live transcript.
