# Persistent Planning

> Transforms Claude Code into a Manus-style persistent planner using on-disk markdown files as working memory. Creates structured task directories with taskplan.md and notes.md that persist across sessions. Enables multi-step project tracking, progress visibility, and knowledge storage that survives context resets. Based on proven context engineering principles for long-horizon AI tasks.
