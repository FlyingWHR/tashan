# Open Ontologies

> AI-native ontology engineering with 39 MCP tools backed by an in-memory Oxigraph triple store. Build, validate, query, and govern RDF/OWL ontologies using a generate-validate-iterate loop. Supports SPARQL querying, SHACL validation, OWL-RL reasoning, Terraform-style lifecycle management (plan/enforce/apply/monitor/drift), data ingestion from CSV/JSON/XML/XLSX/Parquet, clinical terminology crosswalks (ICD-10, SNOMED CT, MeSH), and ontology alignment with self-calibrating confidence. Written in Ru
