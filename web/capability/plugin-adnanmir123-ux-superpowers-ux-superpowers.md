# UX Superpowers

> User-centered design methodology for coding agents. Before you brainstorm solutions or write code, UX Superpowers guides you through structured UX discovery: identifying who you're building for (personas), what they're trying to accomplish (jobs-to-be-done), how they experience the problem today (user journey maps), and how you'll know if you succeeded (telemetry and success metrics). Accepts raw user research data (interviews, surveys, support tickets, analytics) or guides discovery from scratc
