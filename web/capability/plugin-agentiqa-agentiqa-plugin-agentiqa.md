# Agentiqa

> AI-powered QA testing agent for web and mobile apps. Agentiqa explores your app visually - like a real user with fresh eyes - and reports bugs with severity, confidence scores, and step-by-step reproduction instructions. No selectors, no scripts, no test code to maintain. Just describe what to test in plain English. Supports web (any URL or localhost), Android (emulator/device), and iOS (simulator/device). Finds visual bugs, logical errors, UX issues, and accessibility problems that unit tests
