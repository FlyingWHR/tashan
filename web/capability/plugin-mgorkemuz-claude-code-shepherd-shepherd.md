# Shepherd · mgorkemuz

> Shepherd tracks, preserves, and auto-cleans the background processes Claude Code's Bash tool leaves running dev servers, build watchers, test runners. Each Claude session gets its own tracked list, so you can stash a dev server to free RAM, bring it back later in the same working directory, kill just one session's processes without touching another's, and when Claude crashes have its orphaned children cleaned up automatically on the next launch.
