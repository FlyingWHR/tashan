# Claude Transcribe

> Transcribe video and audio from URLs (YouTube, X/Twitter, TikTok, Vimeo, podcasts) or local media files into plain-text transcripts using yt-dlp + OpenAI Whisper. Auto-triggers when you ask Claude to research, transcribe, summarise, or take notes on a video. Runs entirely on-device — no audio is uploaded anywhere. Browser cookies are passed to yt-dlp automatically so age-gated and members-only sources work for signed-in users.
