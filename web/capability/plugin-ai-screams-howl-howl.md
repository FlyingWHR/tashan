# Howl

> Howl is a blazing-fast Go statusline HUD for Claude Code. It reads JSON telemetry from stdin and renders a rich ANSI statusline with 13 real-time metrics: model badge, context usage bar, session cost, duration, git status, code changes, response speed, cache efficiency, API wait ratio, cost velocity, OAuth quota, active tools, and running agents. Features adaptive layouts (2-4 lines normal, 2 lines danger mode at 85%+ context), 4 configurable presets, 12 individual metric toggles, and ...
