# Code Music

> Enjoy background music while your AI coding agents do the heavy lifting. Stream lo-fi, jazz, classical, ambient, electronic, synthwave, and more—live from the internet, right in your terminal. No setup, no accounts, no ads. Features include an AI DJ that reads your session context and automatically picks the perfect genre, a built-in Pomodoro timer, and 30+ curated stations from the internet. Works on macOS, Linux, WSL2, and Windows.
