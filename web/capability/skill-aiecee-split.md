# Split

> Splits mixed local git changes into a small coherent commit series by inspecting staged, unstaged, working tree, or branch diffs, grouping related files and hunks, and staging only the next safe commit slice when staging is possible. Use when the user asks to split changes, prepare separate commits, organize a messy diff, or when a change set contains unrelated concerns.
