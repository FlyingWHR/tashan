# Count Tongulas Workspace

> Create team workspaces with shared context across multiple repos. Run /count-tongulas-workspace:create and walk through an interactive setup — enter your team name and repos, and it scaffolds everything: a repo registry (repos.json) with GitHub metadata, a CLAUDE.md with repo map and deployment table, a Makefile with workspace commands, and a bootstrap script that clones all repos. Designed for teams working across many repositories who want Claude Code to understand the full system.
