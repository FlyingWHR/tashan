# Dep Diff · DigiCatalyst-Systems

> Translates a lockfile diff into a human-readable upgrade plan for npm and PyPI. Point your AI assistant (Claude Desktop, Claude Code) at a Dependabot PR, npm outdated output, or any pair of package versions, and get back a ranked upgrade plan: semver class, breaking changes pulled from GitHub release notes, CVEs fixed in the range, migration guide links, and a clear recommendation per package.
