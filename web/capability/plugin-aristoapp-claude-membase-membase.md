# Membase

> Membase connects Claude Code to Membase Cloud, giving Claude persistent memory and wiki workflows across coding sessions. It can recall relevant prior context before prompts, save durable project decisions and user preferences, and search stable wiki documents while you work. The plugin includes slash commands, MCP tools, project-aware recall, optional summary capture, and privacy safeguards for avoiding secrets, raw source files, and private blocks.
