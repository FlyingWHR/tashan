repo-doctor

plugin:livlign/claude-skills/repo-doctor · plugin

repo-doctor diagnoses README "shape problems" — the hero never lands, install-to-first-success buries the lede, the "what is this" sentence assumes prior context, the badge row is louder than the content — and produces a prioritized punch list a maintainer can act on in an afternoon. Read-only by default; opens a PR only when the user explicitly asks. Key features: - 9-criterion rubric scored 1–5 with cited line numbers and one-line fixes - Rubric weighting adapts to inferred repo category: lib

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
