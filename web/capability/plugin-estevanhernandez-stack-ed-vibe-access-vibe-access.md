# Vibe Access

> Give agents pipelines into your app — then see the surface an agent actually sees. Scans your routes and auth model, maps every callable surface into a schema-versioned agent-access.json manifest with dev and prod-safe tiers, mines the input shape a caller must send, scaffolds the affordances your app is missing behind hard env gates, and proves the layer with a cold-agent verify. /vibe-access:visualize renders the whole surface — or a live MCP server's tools/list — into one self-contained HTML
