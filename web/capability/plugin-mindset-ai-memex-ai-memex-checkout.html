Memex Checkout

plugin

Binds your coding thread to a Memex Spec and records in-flow edits against it (claim-gated, privacy-first). Hooks-only and trivially uninstallable; the Memex MCP is planted by npx -y memex-ai install (one sign-in serves both, no duplicate toolset). Sends only changed file paths + the claimed spec; never source code or prompts.
