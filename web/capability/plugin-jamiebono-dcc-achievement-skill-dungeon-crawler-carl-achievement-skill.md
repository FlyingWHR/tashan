# Dungeon Crawler Carl Achievement Skill

> Generates achievement notifications in the voice of the System AI from Matt Dinniman's Dungeon Crawler Carl series. Give it any real-world situation — a missed deadline, a meeting that could have been an email, a spectacular git commit — and it produces a full achievement notification with title, trigger line, sarcastic commentary, tier-appropriate loot box, and a thematically named reward. Uses the --loot flag to add RPG-style item reveals with descriptions that editorialize on your life choice
