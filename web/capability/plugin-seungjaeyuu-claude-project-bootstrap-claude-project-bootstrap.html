Claude Project Bootstrap

plugin

네거티브 우선 원칙, 베이스라인 테스트 하네스, pre-commit 가드로 새 Claude Code 프로젝트를 부트스트랩합니다. 대화형 질의를 통해 CLAUDE.md, 테스트 프레임워크 문서, accessibility/중복키 검사, 4단계 Bash 권한 시스템을 생성합니다. 실전 프로젝트에서 검증된 패턴이 다음 프로젝트의 기본값이 됩니다. Bootstrap new Claude Code projects with negative-first rules, a baseline test harness, and pre-commit guards. Generates CLAUDE.md, testing framework docs, accessibility/dict-duplicate checks, and a 4-tier Bash permission system — all through interactive prompts. Patterns from real production projects become

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
