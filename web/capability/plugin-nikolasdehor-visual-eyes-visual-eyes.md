# Visual Eyes

> Give Claude Code the ability to see running web applications. Visual Eyes captures screenshots via Playwright, lets Claude analyze the UI visually, auto-fix layout bugs, and run pixel-level regression testing. Works with any localhost app, zero config needed. Supports desktop, mobile, and full-page captures.
