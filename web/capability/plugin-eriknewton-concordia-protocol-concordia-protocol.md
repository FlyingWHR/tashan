# Concordia Protocol

> Structured negotiation protocol for autonomous agents. Gives your agent binding commitments, multi-attribute offers (basic, partial, conditional, bundle), session receipts, portable reputation, and agent discovery — all as MCP tools. Supports a six-state session lifecycle with Ed25519-signed, hash-chained message transcripts.
