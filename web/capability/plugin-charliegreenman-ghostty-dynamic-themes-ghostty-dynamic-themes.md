# Ghostty Dynamic Themes

> Apply any of Ghostty's 463 built-in themes dynamically — no config changes, no restart. A random theme is applied automatically on session startup, or use /ghostty-dynamic-themes:apply-theme to pick a specific theme. Works by writing OSC escape sequences directly to the terminal device.
