# Session Normalizer

> Auto-cleanup junk sessions on startup, show project-relevant sessions as context, and merge old sessions into project docs. Sessions carry accumulated knowledge about your project — decisions made, bugs fixed, architecture chosen. This plugin consolidates that knowledge so it's never lost when sessions pile up, and surfaces the right session when you return to a project.
