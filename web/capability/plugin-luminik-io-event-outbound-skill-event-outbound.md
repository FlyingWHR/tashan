# Event Outbound

> Create buyer-first email and LinkedIn outreach for B2B trade shows and conferences. Give event details, ICP, target personas, and sender context. event-outbound drafts pre-event, day-of, and post-event touches, then validates each one locally for channel length, subject quality, inbox preview, buyer focus, CTA clarity, forced event phrasing, and common AI-sales cliches. Built by Luminik from 20K+ outbound touches reviewed across 50+ events. Runs inside Claude Code with no extra API key.
