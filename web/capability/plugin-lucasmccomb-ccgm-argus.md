# Argus

> /argus - a closed-loop visual-ATDD harness where the agent develops UI against a per-feature design spec and signs off on its own work (functional AND visual) by grounding every judgment in deterministic gates plus a SEPARATE judge subagent that scores the render against the spec, a reference image, and the design system — never the diff.
