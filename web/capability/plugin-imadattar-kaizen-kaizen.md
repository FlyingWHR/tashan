# Kaizen

> Continuous improvement toolkit for Claude Code. Instead of dumping a dozen skills upfront, kaizen starts with a single skill — /kaizen:coach — that analyzes your actual workflow and suggests only what you need: the right skills, hooks, rules, and a well-structured CLAUDE.md. Once your environment is healthy, /kaizen:code handles the full dev pipeline: diagnose → implement → verify → commit.
