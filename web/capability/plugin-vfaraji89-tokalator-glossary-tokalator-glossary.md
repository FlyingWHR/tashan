# Tokalator Glossary

> Auto-generates a codebase glossary (symbol index) after /init or on demand. Scans Python, JavaScript, and TypeScript files using AST parsing to map every class, function, and export with file path and line number. The glossary acts as a compressed context layer , Claude can consult it instead of reading files, saving thousands of tokens per session.
