# Conductor

> Teach Claude to orchestrate microservices and business processes with Conductor. This skill adds full workflow lifecycle management: define workflows with any task type (HTTP, SWITCH, FORKJOIN, WAIT, HUMAN), run them synchronously or asynchronously, monitor executions, and manage failures with pause/resume/retry/restart. Key capabilities: - Create workflow definitions with proper JSON schema and input expressions - Start, monitor, and search workflow executions by status, time, or correlation
