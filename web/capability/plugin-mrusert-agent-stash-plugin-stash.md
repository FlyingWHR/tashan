# Stash

> Give Claude persistent cloud memory that survives beyond a single session. Developers can stash working state, share context between parallel agents, and coordinate multi-agent workflows using named text files. Includes ephemeral stashes that auto-expire, persistent keeps that never expire, and channels as append-only streams for coordination. Free tier included — no setup required.
