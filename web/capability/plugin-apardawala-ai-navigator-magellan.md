# Magellan

> Enterprise knowledge discovery and process repository. Point Magellan at a folder of collected materials — code, documents, meeting transcripts, API specs, diagrams — and it builds a structured, queryable knowledge graph organized by business domain. Then use the knowledge graph to research, plan, and execute work with full context at every stage.
