# Cync

> Cync backs up and syncs your Claude Code settings to any Git repository. Push your ~/.claude/ configuration from one machine and pull it on another — keeping CLAUDE.md, custom skills, commands, memory, and settings in sync across all your devices. Features module-based selective sync, sensitive data scanning, optional AES-256-GCM encryption, dry-run previews, and interactive conflict resolution.
