Nova Thesis

plugin

nova-thesis challenges technical implementations before they ship. Present any implementation — a problem statement, a design sketch, a code snippet, or a full repository — and the skill refuses to accept it at face value. It scores the work across five dimensions (Correctness, Completeness, Scalability, Security, Maintainability), surfaces a real-world incident from an index of public postmortems that matches the riskiest gap, and asks hard, specific questions anchored to that incident.
