# Enam

> Persistent memory for Claude Code — at ~350 tokens ambient cost, with no Docker, no API keys, and no MCP servers. Engram captures your sessions structurally on PreCompact (zero LLM cost), extracts atomic memories via a single lightweight LLM digest (preferences, practices, current context), and detects emergent patterns from your history — files you always edit together, recurring errors, tool usage anomalies — stored as an auditable Obsidian-compatible wiki.
