# Diataxis

> A plugin for improving project documentation using the Diataxis framework. It surveys an existing codebase, classifies current documentation as tutorials, how-to guides, reference, or explanation, identifies gaps and mixed-purpose docs, proposes a structured documentation plan, and writes approved documents one at a time with user review at every stage.
