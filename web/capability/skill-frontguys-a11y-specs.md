# A11y Specs

> Expert accessibilité pour la production de spécifications opérationnelles destinées aux équipes produit et design. Utilise ce skill dès qu'une demande porte sur la rédaction de specs d'accessibilité, que ce soit pour un ticket Jira / US (critères d'acceptance, exigences techniques) ou pour des annotations de maquettes (format court pour la passation Design - Dev). Déclencher pour : "rédige les specs a11y de ce composant", "écris les critères d'acceptance accessibilité", "annote ce composant pour Figma", "quelles specs pour ce tunnel / formulaire / modale / stepper / navigation", "j'ai un brief sur ce composant, génère les specs", "rédige la partie accessibilité du ticket". Déclencher aussi si une capture d'écran est fournie avec une demande de specs ou d'annotations. Ce skill s'appuie sur a11y-rgaa pour valider la conformité normative de ce qui est proposé — toute exigence produite doit être vérifiable RGAA.
