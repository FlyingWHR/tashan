claude-code-el-slack

plugin:mividtim/claude-code-el-slack/claude-code-el-slack · plugin

Slack event source for the el (event-listeners) plugin. Listens for real Slack messages via a one-shot webhook server with high watermark deduplication, bot filtering, edit detection, and @mention handling. Enables Claude Code agents to respond to Slack channel activity in real time without polling. Pairs with ngrok for public webhook URLs.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
