# Searching Apple Notes

> Semantic search and note creation for Apple Notes. Talk to Claude in natural language — it searches your notes by meaning (not keywords), answers with citations, and writes new notes back. Powered by BGE-M3 embeddings and ChromaDB, all running locally on your Mac. No API keys, no cloud services. Native support for Chinese-English mixed content and 100+ languages.
