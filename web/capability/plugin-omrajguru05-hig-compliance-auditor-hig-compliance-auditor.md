# Hig Compliance Auditor

> Audits codebases and design systems against Apple's Human Interface Guidelines. Scans SwiftUI, UIKit, CSS, HTML, and JavaScript for HIG violations across iOS, iPadOS, macOS, watchOS, tvOS, visionOS, and Web/PWA targets. Generates structured compliance reports with severity tiers (Critical, High, Medium, Low), platform-specific guidance, accessibility audit results, and actionable remediation options. Applies fixes on user approval with inline attribution comments referencing the specific HIG gui
