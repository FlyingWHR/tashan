# PDF Forge

> Professional PDF generation with Tailwind CSS. Generates slide presentations (16:9) and A4 documents from any content using a complete design system — typography scales, spacing grids, color palettes, and 15 ready-to-use templates. Renders via Playwright/Chromium. Includes brand customization, anti-AI-sloppy aesthetics (zinc backbone, negative tracking, restrained accents), and an MCP server for Claude Desktop integration.
