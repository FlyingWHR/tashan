Excalidrawer

plugin

Code-first Excalidraw diagram generation with SVG and PNG export. Say "draw a flowchart" or "create an architecture diagram" and it just works — no browser required. Supports flowcharts, architecture diagrams, sequence diagrams, and timelines from JSON data. Uses resvg-js for fast native PNG rendering.
