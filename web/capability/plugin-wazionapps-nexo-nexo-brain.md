# Nexo Brain

> Cognitive co-operator that gives AI agents persistent memory, learning, and work continuity. Includes session management, episodic/semantic memory (Atkinson-Shiffrin model), overnight learning (Deep Sleep), autonomous processes, trust scoring, adaptive calibration, unified diagnostics, and a web dashboard. Turns a stateless LLM into an operational partner that remembers, learns from mistakes, and improves over time.
