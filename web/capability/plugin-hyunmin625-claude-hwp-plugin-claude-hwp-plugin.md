# Claude Hwp Plugin

> Control HWP/HWPX Korean documents with natural language commands. Supports reading and summarizing documents, auto-filling form fields, batch generating documents from data, creating new HWPX files from markdown, and comparing document versions. Built on the kordoc library with full MCP integration for Claude Code.
