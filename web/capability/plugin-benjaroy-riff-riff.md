# Riff

> Riff is a plugin made up of nine opinionated skills for writing personal essays with Claude. The idea behind it is to treat writing with AI as a process to be supported instead of a product to be created, and to keep the writer in charge at every step of the way. Together, the skills form a pipeline so a user can start working with raw notes and get to a finished piece, but each skill also encourages time for pausing and reflection when appropriate.
