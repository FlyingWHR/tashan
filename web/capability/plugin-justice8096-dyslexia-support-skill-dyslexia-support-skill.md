# Dyslexia Support Skill

> A Cowork plugin and standalone skill set that provides: Remediation & Cognitive Prosthetics — Evidence-based intervention plans grounded in structured literacy, Orton-Gillingham methodology, and IDA standards. Explicitly distinguishes remediation targets (trainable skills) from bypass targets (persistent deficits requiring permanent cognitive prosthetics: text-to-speech, speech-to-text, audiobooks via Learning Ally/Bookshare, OCR, spell-checkers, dyslexia-friendly fonts).
