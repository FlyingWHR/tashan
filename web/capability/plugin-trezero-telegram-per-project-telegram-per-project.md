# Telegram Per Project

> Telegram channel for Claude Code with per-project bot isolation. Each project gets its own Telegram bot, access policy, and message inbox — so messages to @alphabot reach Terminal 1 and messages to @betabot reach Terminal 2, with no cross-talk. Key features: - Per-project bot tokens via TELEGRAMPROJECTID environment variable - Independent access policies per project, bootstrapped from global conf
