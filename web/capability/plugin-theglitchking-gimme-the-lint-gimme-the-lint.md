# Gimme The Lint

> Progressive linting system that only blocks on new violations, never on legacy code. Baselines existing lint issues by directory, then enforces clean code going forward. Supports Python (Ruff) and JavaScript/TypeScript (ESLint) in monorepo configurations. Includes drift detection, auto-healing, git hooks, and a GitHub Action for CI enforcement. Directory-chunked baselines allow gradual adoption without a big-bang cleanup.
