# Parallax · clomia

> Parallax is an autopilot for long, complex tasks in Claude Code. Append parallaxthink to any prompt, and at the end of each turn Parallax spawns an advisory agent in an isolated context, finds regions the mission implicitly required but the agent never addressed, and surfaces one back into the turn. The loop continues until the task is flawlessly done — turning a single prompt into the equivalent of several manual follow-ups, without any extra effort from you.
