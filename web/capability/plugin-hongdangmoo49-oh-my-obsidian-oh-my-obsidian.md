# Oh My Obsidian

> Claude Code를 위한 영구적인 '두 번째 뇌(Second Brain)'입니다. oh-my-obsidian은 로컬 Obsidian Vault와 Claude Code를 직접 연결하여 AI 에이전트의 가장 큰 취약점인 '문맥 단절(Amnesia)'을 해결합니다. 과거의 아키텍처 의사결정 내역을 자동으로 기록(session-save)하고, 유사한 이슈 발생 시 관련 컨텍스트를 즉시 인출(recall)하여 대화에 다시 통합합니다. 소크라테스식 인터뷰를 기반으로 한 초기 폴더 설계(setup)부터 방대해진 문서 트리를 꼬임 없이 안전하게 재구조화하는 리팩토링(refactor) 기능까지, 내장된 특수 서브 에이전트(Vault Architect 등)들이 개발 팀의 완벽한 로컬 지식베이스 구축을 돕습니다. 자동 Git 동기화 스크립트 기능이 포함되어 새로운 팀원의 지식 온보딩도 단 몇 초 만에 완료됩니다.
