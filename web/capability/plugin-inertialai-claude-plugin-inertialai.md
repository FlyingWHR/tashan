# Inertialai

> Embed and analyze sensor and time-series data using the InertialAI API. Provides MCP tools for embedding, similarity search, and nearest-neighbor classification, plus workflow skills for IMU session analysis, anomaly detection, and session comparison. Embeddings are stored locally and referenced by handle so high-dimensional vectors never enter the model's context window.
