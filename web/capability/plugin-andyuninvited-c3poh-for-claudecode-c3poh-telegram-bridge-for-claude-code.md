# C3poh Telegram Bridge For Claude Code

> DM your Claude Code agent from your phone and get answers back. C3Poh connects Claude Code to Telegram using long-polling, so there are no webhooks, no inbound ports, and no ngrok. All traffic is outbound-only. Access is locked to an allowlist of Telegram user IDs you configure. Bot tokens stay out of config files. Integrates with TinMan to receive heartbeat alerts on your phone. Requires only Python 3.9+ and Claude CLI.
