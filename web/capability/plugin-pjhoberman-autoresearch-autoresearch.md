# Autoresearch

> Autonomous experiment loops on any codebase — one file, one metric, one loop. An agent edits a constrained file, runs an eval, keeps improvements, reverts failures, and repeats unattended. Based on Karpathy’s autoresearch pattern, generalized beyond ML training to any code with a measurable outcome.
