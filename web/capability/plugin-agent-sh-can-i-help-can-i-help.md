# Can I Help

> Contributor guidance for any project — matches developer skills to data-backed contribution opportunities. /can-i-help collects project-health signals automatically (good-first-issue candidates, test gaps from co-change history, doc drift, bug-spots, open GitHub issues), asks about the developer's background, then matches skills to needs with concrete next steps. Each recommendation includes what to do, why (with the underlying data), how (reads relevant code and explains), and the first step.
