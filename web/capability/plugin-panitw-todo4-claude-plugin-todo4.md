# Todo4

> Todo4 gives Claude Code a durable memory for your work. Ask Claude to create tasks, log follow-ups mid-debugging, or break an epic into subtasks — and those tasks persist across sessions, projects, and even other agents (Claude Cowork, OpenClaw). There are 16 MCP tools cover the full lifecycle (create, update, close, comment, subtasks, tags, notifications) plus a /todo4:status command for a quick overdue / due-today dashboard. Free tier available, OAuth sign-in handles auth on first use.
