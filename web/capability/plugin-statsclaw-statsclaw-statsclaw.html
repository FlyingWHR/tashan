Statsclaw

plugin

StatsClaw orchestrates 9 specialized AI agents (leader, planner, builder, tester, scriber, simulator, distiller, reviewer, shipper) through 13 workflows — from simple code changes to Monte Carlo simulation studies. Features include two-pipeline isolation for adversarial verification, automatic credential detection, shared knowledge brain system, and workspace-synced audit logs. Users just describe what they want in plain language; the leader agent handles the rest.
