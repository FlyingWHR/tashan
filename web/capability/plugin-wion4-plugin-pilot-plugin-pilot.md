# Plugin Pilot

> AI-driven plugin lifecycle manager for Claude Code. Automatically detects which plugins, skills, and stacks are relevant to your current task based on project files, frameworks, and context. Searches official marketplace and GitHub for matching tools, tracks usage to suggest cleanup of unused plugins, and integrates into plan mode. Includes legal framework (TOS, Privacy Policy), trust scoring for community plugins, and system language detection
