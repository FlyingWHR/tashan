# Gws Connector

> Multi-account Google Workspace MCP server — connect multiple Gmail, Google Calendar, and Google Drive accounts with smart routing. Target accounts by label, email, or domain. Supports per-account OAuth credentials for different organizations. 21 tools for mail (search, read, draft, send, labels), calendar (list, get, create), and drive (search, read, list). Tokens stored securely in OS keychain.
