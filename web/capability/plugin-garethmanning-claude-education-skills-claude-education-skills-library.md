# Claude Education Skills Library

> 108 evidence-based pedagogical skills for educators — the only education-specific skills library in the Claude ecosystem. Covers curriculum design, lesson planning, assessment, learning science, wellbeing, EAL, professional learning, and AI tutoring design across 14 domains. Every skill is grounded in named peer-reviewed research with explicit evidence ratings. Frameworks without empirical support (learning styles, brain gym, VAK) are excluded by design.
