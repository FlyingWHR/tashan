# Jira

> jira is a Claude Code plugin that brings full Jira issue management into your editor. It wraps the jira-commands CLI (written in Rust) and exposes 9 skills covering the most common Jira workflows: listing and viewing issues, creating issues with dynamic custom field prompts, transitioning statuses, logging time, uploading attachments, running bulk operations via JQL, and making raw REST API calls. The plugin reads credentials from ~/.config/jira/config.toml (set up via jira auth login) — no e
