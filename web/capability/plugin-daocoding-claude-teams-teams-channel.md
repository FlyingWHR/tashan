# Teams Channel

> Microsoft Teams channel for Claude Code. Connects a Claude Code session to Microsoft Teams via an MCP server with Bot Framework webhook. Delivers inbound Teams messages as channel notifications and provides reply, react, edit, and file download tools. Includes pairing-based access control so any approved user in your organization can message your Claude Code agent directly on Teams.
