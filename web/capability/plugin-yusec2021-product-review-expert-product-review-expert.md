# Product Review Expert

> product-review-expert is a Claude Code plugin for structured product and UX review. It is intended to help users analyze product requirement documents, workflow descriptions, page plans, and interaction designs before implementation or release. The plugin focuses on surfacing concrete quality issues rather than generating generic feedback. Its review scope includes workflow completeness, state-transition coverage, exception and edge-case handling, role and permission consistency, rule conflicts
