# Swagger Contract Testing Openapi Parser

> OpenAPI Parser for Drift Test Generation Parses complex OpenAPI 3.x specifications and generates structured Drift test cases from them. Handles advanced schema patterns including anyOf/oneOf/allOf, discriminators, polymorphism, inheritance, $ref chains, enums, regex patterns, and optional fields. Produces ready-to-use Drift operation YAML and dataset YAML, with a clear analysis of schema variants and any identified coverage gaps.
