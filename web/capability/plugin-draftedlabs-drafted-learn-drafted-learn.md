# Drafted Learn

> Displays an AI/ML fact in your terminal every time you submit a prompt to Claude. Covers 94 facts across 8 categories — tokenization, transformers, RLHF, agent architecture, training data, ethics, and more — rotating randomly so you learn passively while Claude is thinking. Zero extra time required. Built by Drafted Labs for university students entering the AI field.
