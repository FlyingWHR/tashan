# Phone A Friend Paf

> Phone a Friend lets Claude Code call other AI coding backends for second opinions, code review, and multi-agent collaboration. It relays your prompt and repository context to Codex, Gemini, OpenCode, or local Ollama models, then brings the response back into your Claude session. Includes streaming, structured JSON output, session continuity, multi-agent orchestration with a web dashboard, and an interactive TUI. Useful when you want a different model's perspective without leaving Claude Code.
