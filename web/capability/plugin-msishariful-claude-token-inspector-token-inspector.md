# Token Inspector

> Two skills that help you understand and optimize your Claude Code context window. Inspect Context gives you a full token breakdown by source (files, history, skills, MCP configs) with a keep/remove recommendation for each. Find Bloat scans everything loaded and surfaces what's burning tokens without contributing to your current task — with exact commands to remove it.
