# Plugin Manager

> Visual web UI for managing Claude Code plugins. Opens as a standalone browser window with an Anthropic-styled interface. Browse all installed plugins with detailed views of skills, agents, commands, hooks, MCP servers, and modes. Toggle plugins enabled/disabled with one click. Search across plugin names, descriptions, and skill names. Filter by source (Official/Community) and status. Explore the marketplace with available plugins. Features dark mode, keyboard shortcuts, toast notifications, SSE
