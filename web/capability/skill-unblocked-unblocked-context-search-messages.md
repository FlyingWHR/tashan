# Unblocked Context Search Messages

> Messaging-only search via contextsearchmessages. Use this instead of contextresearch when you want team conversation results — Slack threads, channel discussions, and chat history — without PR, issue, or doc noise mixed in. TRIGGER when: finding what the team discussed or decided in chat; surfacing informal context around a feature, incident, or decision; the user asks "did anyone discuss X", "was there a conversation about Y", "what did the team say about Z", or "who has been talking about this". DO NOT TRIGGER when: you need the current code state — use Grep/Glob/Read; you need PRs, issues, or docs alongside messages — use contextresearch instead.
