# Paper Review System

> Automated academic paper review system for Claude Code. Integrates PDF parsing (marker-pdf + PyMuPDF), reference verification (CrossRef + DBLP + Semantic Scholar), SOTA comparison, and competitive paper analysis within a structured multi-phase review pipeline. Features venue-adaptive review strategies for 15+ top CS conferences (CVPR, NeurIPS, ICML, ICLR, ECCV, ICCV, ACL, AAAI, KDD, MICCAI, etc.), powered by distilled methodologies from 10 senior conference reviewers. Includes 8-dimension scori
