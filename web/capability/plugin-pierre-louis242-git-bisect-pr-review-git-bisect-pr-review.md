# Git Bisect Pr Review

> Two skills in one plugin: (1) Automated git bisect for regression hunting — establishes boundaries, runs git bisect run with reproduction commands, analyzes the culprit commit, and suggests fixes. (2) Structured PR review — loads PR context via gh CLI, reviews across five dimensions (code quality, test coverage, security, performance, CI status), posts inline and general comments, handles approvals, and merges with the repo's preferred strategy. Includes safety rails: never merges without us
