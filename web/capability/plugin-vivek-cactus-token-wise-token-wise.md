# Token Wise

> A Claude Code plugin that routes text-heavy tasks to the right Claude model — saving tokens without sacrificing quality. Why Planning, CLAUDE.md generation, README writing, and PRDs don't need Opus when you're just structuring content. token-wise intercepts these tasks and runs them on Sonnet or Haiku instead, switching back to your session model automatically when done.
