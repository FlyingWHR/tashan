# Nitrograph

> Nitrograph is a service-discovery network for agents. It helps probabilistic agents transact with deterministic headless payment endpoints. This plugin lets Claude search a curated registry of agent-usable APIs (x402, MPP, and standard HTTP) ranked by trust, reliability, and price, then fetch the exact endpoints, OpenAPI spec, gotchas, and proven multi-step patterns needed to call them.
