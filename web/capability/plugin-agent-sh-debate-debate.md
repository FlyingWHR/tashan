# Debate

> Structured multi-round debate between AI tools with proposer / challenger roles and a final verdict. /debate orchestrates a back-and-forth between two AI CLIs (Gemini, Codex, Claude Code, OpenCode, Copilot, Kiro) on a design decision, technical question, or contested approach. Each round, one tool proposes / defends and the other challenges; the orchestrator synthesizes the disagreement and renders a verdict with reasoning. Surfaces blind spots that single-tool consultation misses, especially
