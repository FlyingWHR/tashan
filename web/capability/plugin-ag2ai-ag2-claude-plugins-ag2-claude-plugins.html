ag2-claude-plugins

plugin:ag2ai/ag2-claude-plugins/ag2-claude-plugins · plugin

A Claude Code plugin marketplace for building AG2 (AutoGen) agents and multi-agent workflows. Includes 5 plugins: agent scaffolding (ConversableAgent + A2A server wiring), workflow patterns (two-agent chat, sequential, group chat, nested chat), tool building (function tools + API connectors), agent code review (prompt quality, security, tool contracts), and architecture guidance (pattern selection, system prompt engineering). Apache-2.0 licensed.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
