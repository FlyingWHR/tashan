# Fullstory

> This is a Fullstory MCP plugin that connects Claude Code (or Cowork) to Fullstory's behavioral analytics platform. It exposes Fullstory's MCP server, allowing you to query session/event data, analyze user behavior and funnels, retrieve customer experience insights (rage clicks, errors, user journeys), and explore behavioral analytics programmatically — all from within Claude. It includes skills for general analysis and comparisons.
