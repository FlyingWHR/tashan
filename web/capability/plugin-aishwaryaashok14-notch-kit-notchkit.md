# Notchkit

> Build macOS notch apps that live in the MacBook camera notch. Handles the hard parts — notch detection, floating panel (NSPanel), hover expand/collapse animations, the curved NotchShape, and a SwiftUI template with collapsed wings + expanded tray. Clone, edit one file, build. No Xcode project needed.
