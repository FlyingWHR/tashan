# Whatsapp Channel

> WhatsApp channel for Claude Code. Message Claude from your phone, get replies back, and approve tool use remotely. Built on Baileys (WhatsApp Web multi-device). Features QR/pairing code linking, access control with allowlists, group chat support (mention-gated), media handling, and auto-reconnect.
