# Aight

> Aight is a channel plugin that bridges Claude Code to an iOS app via a Cloudflare Workers relay. Users pair with a 6-digit code — no port forwarding, no LAN requirement. The plugin exposes reply and react tools so Claude can send messages, markdown, and file attachments to the phone. It also forwards tool events (Bash, Read, Edit, etc.) in real-time so users can monitor Claude's work from their phone. Built with Bun, TypeScript strict mode, 68 tests. Security: HMAC-SHA256 auth tokens, session-is
