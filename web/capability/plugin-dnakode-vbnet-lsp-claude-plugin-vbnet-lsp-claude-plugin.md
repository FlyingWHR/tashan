# Vbnet Lsp Claude Plugin

> vbnet-lsp adds Roslyn-powered VB.NET language intelligence to Claude Code through Language Server Protocol. It registers .vb files and launches vbnet-ls over stdio, enabling semantic diagnostics, completion, hover, definition/references navigation, and symbol-aware edits in VB.NET projects. The language server is distributed as the NuGet global tool DNAKode.VbNet.Lsp and validated in CI on Windows and Linux, including real Claude plugin validation and command checks.
