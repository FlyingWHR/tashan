# Craft Statusline

> A Claude Code statusline written in bash. Shows model and effort level, a state-aware git branch badge, context window with absolute-token traffic light (yellow at 400k tokens, red at 85%), rolling 5h and 7d rate limits, and optional session cost. Zero Node, zero Python, zero Nerd Fonts. Only requires jq. Bash 3.2 compatible, runs on macOS, Linux, and WSL.
