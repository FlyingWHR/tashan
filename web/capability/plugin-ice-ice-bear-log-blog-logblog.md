# Logblog

> Turn your Chrome browsing history into polished tech blog posts on Hugo/GitHub Pages. Automatically classifies URLs (YouTube, GitHub, docs, web pages), fetches enriched content (transcripts, repo metadata, full text), and uses Claude AI to write and publish deep-dive blog posts — all from a single /logblog:post command.
