# Closed Rings

> Closed Rings is a CLI-first time tracker for developers and freelancers. You open a ring when you start a task, close it when you ship, and the tool captures everything in between — context switches, focus blocks, project totals — so you can stop reconstructing your week from memory. Standup summaries, focus reports, and invoice-ready exports come for free.
