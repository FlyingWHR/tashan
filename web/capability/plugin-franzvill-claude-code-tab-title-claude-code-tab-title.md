# Claude Code Tab Title

> Terminal tab and window titles that show what each Claude Code session is working on, with a busy/idle marker. When you run multiple claude sessions in parallel, every tab title normally collapses to the binary name, so you can't tell which session is doing what. This plugin renames each tab to " <topic" while Claude is working and "· <topic" when it's idle. The topic is auto-extracted from the first prompt of the session and stays sticky until the session ends. Works in VS Code's integrated
