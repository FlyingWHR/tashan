# Phone A Friend

> Phone a Friend is a CLI relay that lets AI coding agents collaborate by sending prompts and repository context to other AI backends. It supports Claude, Codex, Gemini, and Ollama as relay targets. Agents can get second opinions, run multi-agent sessions with persistent communication, and stream responses in real time. It includes an interactive TUI dashboard, TOML configuration, and agentic orchestration mode for multi-agent collaboration.
