Flow Studio Power Automate

plugin

Build, debug, and operate Power Automate cloud flows from Claude Code through Flow Studio MCP. Exposes action-level inputs and outputs, loop iterations, and nested child flow failures so agents can diagnose issues, compare runs, and deploy fixes. Includes skills for flow operations, debugging, and flow scaffolding. Requires a Flow Studio MCP subscription.
