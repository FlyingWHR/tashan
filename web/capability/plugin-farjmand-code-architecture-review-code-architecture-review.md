# Code Architecture Review

> Drop this plugin into any project and ask Claude to "review my architecture." It scans for clean architecture violations, SOLID breaches, code smells, and structural anti-patterns across Node.js, Python, React, Go, and monorepo setups — then hands you a prioritized report with actionable fixes, not just vague warnings.
