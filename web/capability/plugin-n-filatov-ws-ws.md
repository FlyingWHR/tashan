# Ws

> ws is a working set manager for Claude Code. Use /ws:map to describe a feature and Claude automatically identifies relevant files across your codebase, adding them to a focused, navigable list. Use /ws:install to set up the ws CLI on any OS. Working sets are branch-scoped and persistent — switch git branches and your context switches with you. Built for AI-assisted coding workflows where you need to track a curated set of files rather than browse your entire project tree.
