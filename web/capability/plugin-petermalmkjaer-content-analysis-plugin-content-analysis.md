# Content Analysis

> Scientific content analysis for academic research. Supports the full workflow from research question to publication-ready output: codebook development, qualitative and quantitative coding, thematic analysis, and inter-coder reliability assessment. Follows established methodology from Krippendorff, Hsieh & Shannon, Mayring, and Braun & Clarke. Produces structured output files including coded data tables (.xlsx), theme summaries (.md), and reliability reports.
