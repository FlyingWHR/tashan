# Cc Wechat

> WeChat channel for Claude Code — bridges your personal WeChat account to a Claude Code session via Tencent's iLink bot API. Supports two-way messaging (receive WeChat messages, reply from Claude Code) and permission relay (approve/deny tool use from your phone). QR code login via MCP elicitation, sender allowlist for security, and cursor persistence across reconnects.
