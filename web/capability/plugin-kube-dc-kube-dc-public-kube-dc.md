# Kube Dc

> Kube-DC is a Kubernetes-native data center platform. This plugin provides 11 workflow skills for managing the full platform lifecycle — create projects, deploy VMs and containers, provision managed PostgreSQL/MariaDB databases, manage Kubernetes clusters, configure networking (EIPs, Floating IPs, Gateway Routes), handle S3 storage, and set up RBAC access controls. Includes manifest templates, post-action verification checks, and OS image catalogs for 10+ operating systems.
