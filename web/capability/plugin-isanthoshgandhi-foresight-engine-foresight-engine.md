# Foresight Engine

> Strategic intelligence plugin for Claude Code. Give it any real-world forecasting question and it produces a structured four-scenario analysis (Probable, Plausible, Possible, Preferable) backed by live web signals, historical analogues, and deterministic probability scoring. Built on IFTF foresight methodology: STEEEP framework, Futures Cone, Cross-Impact Analysis, and Backcasting.
