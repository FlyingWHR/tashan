# Pencil Dev Skill

> Teaches AI coding tools to design and edit pencil.dev UI files (.pen format) through the Pencil MCP server. Every read and write goes through the MCP for schema validation. Live screenshots show the design as it looks, and the MCP keeps your changes and the editor in sync while the canvas is open. Recognises pencil.dev signals automatically: mentions of .pen, .lib.pen, the Pencil canvas, or a design-system folder all activate the skill.
