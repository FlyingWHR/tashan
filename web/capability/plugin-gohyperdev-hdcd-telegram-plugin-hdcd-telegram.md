# Hdcd Telegram

> Rust-based Telegram channel for Claude Code. Drop-in replacement for the official Bun-based Telegram plugin — same features, 20x lighter. 3.5 MB binary, ~5 MB RAM, <50ms startup. Includes access control (pairing, allowlists, group policies), voice transcription via Whisper, and all 4 MCP tools (reply, react, editmessage, downloadattachment). Auto-downloads the correct binary for your platform on first use. Zero migration — reads existing token and access.json from the official plugin.
