# Wezterm Agent Cards Multipanel Sidebar With Notifications Inspir

> A Claude Code plugin that adds a curses-based sidebar to WezTerm showing your Claude Code sessions as stacked status cards with real-time state tracking. Be notified if your agent needs you! Strongly inspired by CMUX, a native macOS terminal that surfaces AI agent status through vertical tabs and notification rings. WezTerm Agent Cards brings the same idea to Linux (and anywhere WezTerm runs) — using Claude Code hooks, a Python TUI, and a thin Lua module instead of a dedicated terminal app.
