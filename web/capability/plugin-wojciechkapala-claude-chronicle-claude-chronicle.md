# Claude Chronicle

> Bridges Codex Chronicle's screen-recording memory into Claude Code. Codex Chronicle is an OpenAI Codex feature that passively records your screen, runs OCR, and writes a markdown summary every ~10 minutes describing what you have been doing across your apps. This plugin pipes those summaries into Claude Code via SessionStart and UserPromptSubmit hooks, so Claude knows what you have been working on outside the terminal — past activity, current focus, and the live screen. Ships with a /claude-chro
