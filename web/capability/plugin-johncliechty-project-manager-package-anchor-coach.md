# Anchor Coach

> The Anchor curriculum — an interactive, agent-collaborative first-project course. Teaches an absolute beginner to brainstorm, describe, scaffold, build, test, ship, and launch a working web app (Anchor — a local task tracker) in about two hours of session time, then transfers the skill to a project of the student's own choosing.
