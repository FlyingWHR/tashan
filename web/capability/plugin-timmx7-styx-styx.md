# Styx

> The MCP-native AI API gateway for developers building with LLMs. Every app using AI needs API keys, cost control, and provider flexibility — Styx gives you all three through one endpoint. Route requests to OpenAI, Anthropic, Google, or Mistral with automatic failover, track spending in real-time, and manage team access with scoped API keys. Self-hosted, open source, and manageable directly from Claude Code with /styx:setup, /styx:status, and @styx-ops.
