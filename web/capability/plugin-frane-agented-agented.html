Agented

plugin

A text editor for LLMs, not humans. Optimized for the model's cost model: fewer round trips per task (no Read-before-Edit; conflict responses carry the new content, so you reconcile in one call instead of pre-reading every time), tighter token budget (lean tab output, not JSON envelopes; ~5x denser than the built-in Read/Edit shape), inline LSP diagnostics on every save (gopls, rust-analyzer-with-clippy, tsserver+eslint findings come back as diag lines instead of round-tripping through carg
