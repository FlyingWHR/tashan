# Stackhawk Skills For Claude

> Your AI coding agent is also your security team. StackHawk skills teach Claude to find security vulnerabilities as you build, report your security posture across applications, and help you fix what it finds — all without leaving your workflow. No context switching, no tickets to another team. Your agent scans, reports, and remediates. Works with Claude Code, the Claude desktop app, and anywhere Claude skills are supported.
