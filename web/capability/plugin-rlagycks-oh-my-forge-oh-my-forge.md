# Oh My Forge

> oh-my-forge is a Claude Code workflow harness that prevents agent mistakes from repeating. Built on everything-claude-code, it adds an ontology-driven structural error prevention system: every agent failure is classified, routed, and converted into a permanent constraint so the same error cannot structurally happen again. It also includes a Codex delegation system where Claude uses an ontology index as a GPS — reading only a domain entry and a spec doc (~3K tokens) instead of the full source tre
