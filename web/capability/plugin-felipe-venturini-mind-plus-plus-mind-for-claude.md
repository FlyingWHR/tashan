# Mind For Claude

> Mind++ is a free, open-source plugin for Claude Cowork that turns Claude into a proactive knowledge partner. It captures meetings, tracks commitments, delivers daily briefings, and maintains a living knowledge base for your professional and personal life — all stored as plain Markdown in an Obsidian vault.
