memoriant-screen-recorder

plugin:anthropics/claude-plugins-community/memoriant-screen-recorder · plugin

Screen recording for Claude Code. Record demos, tutorials, and bug reproductions directly from your coding session. Claude guides you through capture mode selection (full screen, region, window, or terminal-only), manages the recording session, and converts to optimized GIFs for READMEs and documentation. Works on macOS (screencapture) and Linux (ffmpeg). Includes demo automation for recording plugin showcases.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
