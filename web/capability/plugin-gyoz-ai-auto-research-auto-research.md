# Auto Research

> Autonomous skill improvement through parallel research agents. Inspired by Karpathy's autoresearch methodology, it spawns 5 parallel agents (domain expert, quality auditor, competitive analyst, gap analyst, tech scout), synthesizes findings into ranked proposals, then runs an iterative keep/discard experiment loop to improve any Claude Code skill. Scores skills on 7 quality dimensions and only keeps changes that genuinely improve the composite score.
