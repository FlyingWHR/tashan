# Mdbrain

> A native Claude Code extension that prevents AI from over-refactoring your intentional code. Combines XML-structured protocols (BRAIN/CRAFT/PERF) with a 16-entry false-positive catalog, enforced by a five-layer Safety Net: permissions deny list, PreToolUse hook, tool-scoped subagents, path-scoped rules, and behavioral protocols. Coexists non-destructively with existing CLAUDE.md and memory/.
