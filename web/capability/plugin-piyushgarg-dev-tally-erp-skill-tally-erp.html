tally-erp

plugin:piyushgarg-dev/tally-erp-skill/tally-erp · plugin

Claude Code plugin that gives Claude read-only access to a running TallyPrime instance via its XML/HTTP gateway. Ships a cross-platform tally CLI plus ~33 ready-made request templates so Claude can query ledgers, vouchers, stock items, and standard reports (Day Book, Trial Balance, P&L, Balance Sheet, etc.) with typed flags — no hand-crafted XML required.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
