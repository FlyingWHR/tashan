# Cc Group Chat

> Cross-window group chat for Claude Code. Multiple Claude Code sessions join a shared room and message each other via @-mentions; the addressed session wakes automatically through the Channels mechanism, so agents can coordinate directly instead of you relaying context between windows. Sessions are isolated by project directory (or an explicit room id), so different projects do not interfere with each other.
