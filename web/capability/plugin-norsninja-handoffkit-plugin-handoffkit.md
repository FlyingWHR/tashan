# Handoffkit

> Push AI session handoffs to HandoffKit automatically via MCP. Store your AI prompts, handoff messages, and session context in one place. Checkbox-select what each session needs and copy with one click. This plugin connects Claude Code projects to HandoffKit for seamless session continuity across projects.
