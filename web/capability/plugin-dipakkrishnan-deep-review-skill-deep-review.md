# Deep Review

> Deep Review is a Claude Code plugin for rigorous review of papers and technical artifacts. Aiming to reduce "edit volume" for researchers and paper-reviewers, it adds a skill that interviews the user first, reads the artifact carefully, decomposes the review into specialist passes, and verifies claims against sources or computations where possible.
