# Filestack Claude Plugin

> Filestack is a file handling platform-as-a-service used by thousands of applications for uploads, cloud source ingestion (Google Drive, Dropbox, Instagram, and 14 more), on-the-fly image/video/document processing via CDN, and policy-based security. This plugin brings the full Filestack platform into Claude Code through 10 MCP tools (upload, retrieve, delete, store URL, build and apply CDN transformations, list available transforms, generate security policies, sign policies, generate signed URLs)
