# Gr0m Mem

> Zero-install persistent memory brain for Claude Code that stops the model from re-asking and re-deriving across sessions. Four MCP tools (memwakeup, memrecorddecision, memrecalldecisions, memremember) plus Stop and PreCompact hooks automatically preserve context. SQLite FTS5 default backend requires no extras — pip install gr0m-mem and it works. ChromaDB + Ollama semantic retrieval available on the semantic branch. Includes temporal knowledge graph with mandatory asof filtering, per-corpu
