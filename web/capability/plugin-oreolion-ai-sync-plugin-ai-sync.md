# AI Sync

> Cross-platform AI agent synchronization. When you switch between AI coding tools (Claude Code, Cursor, Codex, Aider, Cline, Windsurf, Copilot), ai-sync maintains a shared .ai-sync/ directory so the next agent picks up exactly where the last one left off — with full context of what was done, what's next, blockers, and build status. Features conflict detection, auto-progress tracking, session audit trails, and adapter files for 9 tools.
