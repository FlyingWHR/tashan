# Context OS

> Context OS helps Claude Code find the right files faster. It builds a local repo graph of paths, symbols, imports, line counts, and hot files, then injects a compact autocontext block with up to five likely file candidates for each prompt. It runs locally with no server, no embeddings, and no telemetry. Live proof in the repo shows 40.9 percent aggregate token reduction across 36 Claude Code calls.
