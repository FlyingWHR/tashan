Cyber Punk

plugin

Automated security vulnerability scanner for Claude Code. Fetches CVE/CWE data from NIST NVD, scans code for vulnerable patterns across 9 languages (JS/TS, Python, Go, Java, Rust, PHP, Ruby, C/C++), generates proof-of-concept exploit scripts, and produces detailed security reports with root cause analysis (WHY/HOW/WHAT) for each finding.

Works with: Claude Code (native)
native: this artifact type is that client's own format

Category: Security — see all ranked ›

Install (Claude Code):

/plugin install cyber-punk@claude-community
