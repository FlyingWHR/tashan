# Terminal Chromium

> Full Chromium browser in your terminal for Claude Code. Launches carbonyl (a terminal Chromium renderer using unicode half-block characters) in a tmux split pane and controls it via CDP (Chrome DevTools Protocol). Browse, click, type, evaluate JS, take screenshots, get accessibility trees, and extract page content -- all programmatically from within a Claude Code session. Works over SSH, renders at 60 FPS, supports WebGL/WebGPU.
