# Duck Duck Duck

> A coding companion that watches your Claude Code sessions and reacts with voice, animations, and optional physical hardware. Scores every prompt and response on-device via Apple Foundation Models — private and free by default. Speaks opinionated reactions, handles permissions by voice, and picks from 10 expressive voices based on the mood of the code. Requires the free Duck Duck Duck macOS companion app (Apple Silicon, macOS 26+). Plugin is located in the plugin/ subdirectory of the repository.
