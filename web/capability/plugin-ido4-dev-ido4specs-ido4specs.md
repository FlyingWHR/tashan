# Ido4specs

> ido4specs is the bridge between a strategic spec and GitHub issues. It analyzes your codebase, decomposes capabilities into implementation tasks with effort, risk, type, and dependency metadata, and produces a structurally-validated technical spec any downstream tool can consume. Key features: - Code-grounded decomposition - parallel Explore subagents ground every task in concrete files, services, and patterns from your actual codebase (not fabricated from the spec) - Structured output enforced
