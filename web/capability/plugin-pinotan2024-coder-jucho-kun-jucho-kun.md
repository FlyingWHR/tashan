# Jucho Kun

> Automates the preliminary investigation phase for Japanese real estate disclosure documents (重要事項説明書). Given a property address, it generates a complete due diligence checklist, extracts key facts from PDFs (registry certificates, urban planning maps, hazard maps), and outputs a structured Excel investigation report. Built for licensed real estate appraisers and agents (宅建士・不動産鑑定士).
