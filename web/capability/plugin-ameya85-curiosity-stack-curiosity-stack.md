# Curiosity Stack

> Curiosity Stack turns any technology signal, market theme, or global event into a structured 6-layer value chain breakdown — through Socratic conversation, not summaries. Each layer builds on the previous: Signal → Mechanics → Cause Tree → Solution Space → Build Requirements → Value Chain Actors → Research Landscape. The India Proxy Agent runs a mandatory sourcing checklist across NASSCOM Deep Tech, DPIIT Startup India, GeM portal, BSE SME / NSE Emerge, and 12 curated India VC portfolio pages —
