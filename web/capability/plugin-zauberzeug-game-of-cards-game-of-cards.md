# Game Of Cards

> Game of Cards (GoC) — agile for the age of agents. GoC turns work into durable, inspectable Markdown cards that humans and AI agents collaborate on. Agents pull cards autonomously, work them under a per-card Definition of Done, and close them via a DoD-gated finish-card skill; humans steer by curating the queue and resolving decision gates. Lineage: XP user stories + Kanban pull + Scrum DoD. The plugin ships 14 skills (kickoff, scan-deck, create-card, finish-card, pull-card, aud
