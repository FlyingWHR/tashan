# Prompt Smith

> Prompt Smith adds the /prompt slash command to Claude Code. It takes a rough prompt and rewrites it for clarity, structure, and precision — then shows a side-by-side preview before execution. Four optimization modes (default, agentic, compact, strict) adapt the rewrite to the prompt's intent. Supports --dry-run for preview-only, --yes to skip confirmation, and --mode to select explicitly. Fidelity first: the optimized prompt always preserves the user's exact intent.
