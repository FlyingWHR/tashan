# Aria Knowledge

> ARIA is automated knowledge capture, management, and application for Claude Code. It actively learns during AI-assisted development sessions — insights, decisions, patterns, gotchas — and promotes validated knowledge into an indexed markdown knowledge base that is proactively applied in sessions and on every edit to improve development and accuracy. It runs in Claude Code, fully local. Core feature sets are: Knowledge Lifecycle — automatic capture from conversations and pre-compaction transcrip
