# Skill Provenance

> Version tracking for Agent Skills bundles across sessions, surfaces, and platforms. When you load a skill into a new session, Skill Provenance reads the manifest, verifies file hashes, flags stale evals, and tells you what needs attention. When you save, it bumps versions, recomputes hashes, and updates the changelog. Works anywhere the agentskills.io standard does (30+ agent tools).
