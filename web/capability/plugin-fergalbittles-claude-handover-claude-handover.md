# Claude Handover

> Capture and transfer project knowledge for team handovers. When someone goes on leave or transitions off a project, this skill helps them dump everything they know — priorities, blockers, people, environments, gotchas, tribal knowledge — into a structured format. When the person picking up the project starts, Claude proactively walks them through everything and surfaces relevant context as they work. Supports bidirectional updates, staleness detection, contact preferences, and optional GitHub-ba
