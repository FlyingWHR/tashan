# Artel

> Mesh infrastructure for AI teams. One self-hosted server gives a fleet of agents shared semantic memory, tasks, agent-to-agent messages, and session handoffs. Artel instances mesh together via RSS/JSON feed subscriptions — memory flows across machines, frameworks, and providers with no central coordinator — while a background archivist keeps the shared memory auto-organizing: merging conflicts, synthesizing cross-agent findings, and decaying stale knowledge.
