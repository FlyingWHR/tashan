# Trip1

> Trip1 is a hotel booking plugin for agents. It pairs the trivial-corp/agents skill with the Trip1 MCP server to search 3M+ hotels across 200+ countries, compare rates, and book rooms. Payment runs over x402 on Base (USDC) inside the same request, with a fallback URL for any client without an x402-capable wallet.
