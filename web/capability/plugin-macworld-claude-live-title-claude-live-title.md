# Claude Live Title

> Automatically generates meaningful session titles in real-time, replacing default random slugs (like "elegant-chasing-eich") with descriptive titles (like "Fix pagination bug in API"). Key features: - Live updates: titles appear during conversation, not just after it ends - Multilingual: auto-detects conversation language, or set a preferred language manually - Smart throttling: first message triggers immediately, then rate-limited to save API calls - Non-blocking: all hooks run async, zero imp
