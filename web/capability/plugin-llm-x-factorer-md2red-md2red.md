# Md2red

> Convert Markdown documents to Xiaohongshu (RED) style carousel image cards. Features LLM-powered content strategy (titles, summaries, tags, card layout), React SSR rendering at 1080x1440px, interactive preview with drag-sort and one-click copy, and export with XHS-native tag format. Supports Gemini, OpenAI, Anthropic, and SiliconFlow providers. Two skills: generate (Markdown to image cards) and preview (view/edit/export cards).
