Html Skills

plugin

Skills for Claude Code that make it output HTML files instead of plain markdown when HTML is the better fit — specs, system diagrams, ERDs, dashboards, slide decks, design tokens, code reviews, timelines, and more. Six of the skills are interactive: you click around in your browser, hit Submit, and the result comes straight back into the same Claude Code session as a notification. No copying, no pasting, no switching windows.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
