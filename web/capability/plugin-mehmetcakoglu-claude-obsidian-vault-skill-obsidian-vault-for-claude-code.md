# Obsidian Vault For Claude Code

> Archives your Claude Code sessions into a persistent, on-disk knowledge wiki that Claude reads back in future sessions — like long-term memory, but inspectable, git-versioned, and split between a global vault (~/claude-vault/) and per-project vaults (docs/vault/) committed alongside your code. A SessionStart hook auto-scans finished transcripts; slash commands bootstrap and ingest them into atomic markdown pages with YAML frontmatter and wiki-links. Output is plain Markdown — Obsidian the app is
