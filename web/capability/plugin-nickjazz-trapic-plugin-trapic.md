# Trapic

> Long-term memory for AI coding assistants. Trapic automatically recalls project knowledge at session start, captures decisions and conventions as you work, detects conflicts using topic-based matching, and flags stale knowledge for review. Works via MCP — zero server-side LLM, all intelligence runs on your client AI.
