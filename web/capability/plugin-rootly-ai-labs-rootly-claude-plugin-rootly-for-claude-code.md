# Rootly For Claude Code

> Rootly integration for Claude Code - bringing enterprise incident management directly into your development workflow. Connects to your Rootly instance to prevent incidents before deployment, accelerate response during outages, and streamline post-incident learning without leaving your terminal. Built for teams using Rootly's incident management platform, this plugin provides: • Pre-deployment safety checks against Rootly's historical incident data • Real-time incident investigation with Rootly
