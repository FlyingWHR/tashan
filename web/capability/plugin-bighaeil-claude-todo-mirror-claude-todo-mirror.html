Claude Todo Mirror

plugin

Mirrors Claude Code's TodoWrite state to per-session Markdown files with hierarchical checkboxes ([x] / [▶] / [ ]). Pin the file in VS Code, Obsidian, or any Markdown viewer for an always-visible task view — no more scrolling back through chat to see what's left. Includes per-session isolation, a multi-session index, and slash commands (/todos-watch, /todos-pause, /todos-resume) for managing the mirror.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
