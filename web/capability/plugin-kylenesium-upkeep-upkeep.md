# Upkeep

> macOS cleanup and update assistant for Claude Code. Scans your Mac for reclaimable disk space, leftover app data, stale caches, broken LaunchAgents, and shell configuration drift, then helps you clean it up safely with your approval. It can also update your AI skills and developer package managers in one pass, including Homebrew, npm, pip, gems, and rustup.
