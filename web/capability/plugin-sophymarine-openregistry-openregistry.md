# Openregistry

> Live, government-identical company data from 27 national registries in one install — MCP server + 10 Skills + 6 slash commands. Walk cross-border ownership chains, run KYC/AML due diligence, detect shell companies, pull live XBRL financial statements, monitor corporate filings, check global name availability. Every response is byte-identical to what UK Companies House, France RNE, Germany Handelsregister, Korea OpenDART, Canada CBCA, 10 US state registries, and more return — no aggregator markup
