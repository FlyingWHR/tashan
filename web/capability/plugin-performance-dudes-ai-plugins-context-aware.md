# Context Aware

> Reference plugin for building context-aware plugins: workflows and agents that route ALL retrieval through the context-mode MCP (ctx), so raw bytes are indexed and searched in a sandbox, never dumped into the window. Requires context-mode (enabled once at the workspace level). Teaches the five patterns (index-once-slice-many, fetch-and-index, plain-JS glue, structured-output handoffs, lean orchestrator) and ships a runnable, domain-agnostic demo. Command: /context-aware
