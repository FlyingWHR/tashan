# Evalview

> Behavior regression testing for AI agents. EvalView detects when your agent's behavior drifts e.g changed tool calls, different outputs, or degraded quality even when traditional tests still pass. Snapshot baselines, check for regressions, and auto-heal flaky results, all from inside Claude Code.
