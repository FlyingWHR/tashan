# Clawlock

> Identity, credential vault, and audit security for AI agents. ClawLock gives every AI agent its own Ed25519 cryptographic identity, stores API keys in an AES-256-GCM encrypted vault, enforces least-privilege scopes, and maintains an immutable audit trail of every action. Includes 4 auto-activating skills (security scanning, agent identity management, credential vault, audit log analysis) plus 14 MCP tools via the built-in ClawLock MCP server.
