# My Claude Lang

> Until now, the best AI coding tools required you to speak English. Not anymore. my-claude-lang is a plugin for Claude Code that lets you build software in your native language — with zero English knowledge required. No configuration. No language settings. Just start talking. It understands. This is not a translator. Translators convert words. my-claude-lang converts meaning.
