# Python Clean Architecture

> Scaffold, review, and refactor Python projects with clean code and architecture. Design principles and patterns implemented the Pythonic way — using Protocol, Callable, functools.partial, and closures instead of heavy class hierarchies. Includes a /review-architecture command, layered FastAPI project scaffolding, and reference guides for 7 design principles, 17 code quality rules, and 10 Pythonic pattern recipes. Inspired by Arjan Codes.
