# Claude Voice

> Multilingual voice input for anywhere you type into Claude — Desktop App, Code Desktop, or regular Code terminal. Hold a hotkey, speak any of 99 Whisper languages, transcript pastes into whatever Claude window has focus. Fills the gap while official voice mode is English-only. Lightweight plugin — no MCP, no TTS. (Windows-tested; macOS/Linux feedback welcome.)
