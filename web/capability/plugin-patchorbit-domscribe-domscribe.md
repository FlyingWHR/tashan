# Domscribe

> Domscribe bridges your running frontend and your code editor. Click any element in the browser to tell Claude what to change, or let Claude query any source location to see live props, state, and DOM — directly from the running app. Build-time stable IDs, deep runtime context via React fiber walking and Vue VNode inspection, framework-agnostic (React, Vue, Next.js, Nuxt), and zero production impact.
