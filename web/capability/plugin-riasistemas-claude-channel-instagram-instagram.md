# Instagram

> Instagram channel for Claude Code — read and reply to comments via the official Meta Graph API. HTTP webhook receiver with HMAC-SHA256 signature validation, three MCP tools (replycomment, listcomments, chatmessages), two skills (/instagram:configure, /instagram:access). Modular by design: optional extensions module via INSTAGRAMEXTENSIONSDIR adds CRM/automation hooks without polluting the public core. No Web reverse-engineering — uses Cloud API end-to-end. Apache 2.0.
