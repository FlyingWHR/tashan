# Claude Channel Feishu

> This plugin connects Feishu (Lark) IM to Claude Code as a messaging channel. It runs an MCP server with tools such as reply, react, pair, attachment download, and message edit, while a WebSocket long connection subscribes to im.message.receivev1 so inbound bot messages are delivered into the active session as channel events. Built-in access control covers DM pairing, allowlists, opt-in group chats by chatid, @-bot detection, and optional keyword substring matching. State and policy live under
