# Officecli

> OfficeCLI is a Claude Code plugin for local Office document workflows. It helps Claude create, update, and convert Office files when the local OfficeCLI installation supports the requested task. The plugin is intended for workflows such as: - creating PowerPoint presentations in pptx - creating Word documents in docx - creating structured worksheets in xlsx - checking whether a requested Office workflow is supported before execution The plugin packages a Claude Code skill and routes supported
