# Rich Statusline

> Displays a rich, real-time status line at the bottom of your Claude Code session showing contextual information about the current conversation — including the active model, token usage, cost estimate, current working directory, git branch, and tool activity. Keeps essential session metadata visible at a glance without interrupting your workflow.
