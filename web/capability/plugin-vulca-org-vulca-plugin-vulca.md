# Vulca

> Vulca adds agent-native visual workflows to Claude Code: visual discovery, brainstorm/spec/plan artifacts, structured prompt composition, semantic layer decomposition, and L1-L5 cultural evaluation. It is designed for reviewable image work instead of one-shot prompting, with local-first defaults and explicit opt-in for provider-backed generation, editing, and evaluation.
