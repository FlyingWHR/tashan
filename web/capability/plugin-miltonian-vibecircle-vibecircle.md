# Vibecircle

> See what your friends are building. A social feed for friend groups who vibe code — share screenshots, deploy links, and coding activity with your circle. Features: auto-capture from Claude Code via /share command, live app embeds, reactions and comments, ambient presence (see who's building right now), and AI-powered project explanations (BYOK). Includes /circle setup for zero-friction device code authentication, and /share for posting updates. Open source, MIT licensed.
