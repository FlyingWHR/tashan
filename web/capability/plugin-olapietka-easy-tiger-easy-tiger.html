Easy Tiger

plugin

Catches scope creep in real time. When you ask Claude for a feature that's drifting from what you came to build, easy-tiger casually asks if you actually need it for shipping - then offers to park it for later. It's a friendly nudge, never a blocker, and stays silent when you're on track.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
