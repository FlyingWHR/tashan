# Tianluo

> Keep Claude Code on a multi-hour task without it pinging you at 3am. Tianluo (田螺姑娘) is a methodology skill for multi-hour to multi-day autonomous Claude Code runs. It teaches Claude how to design and drive cron-driven, multi-stage tasks that survive context compaction, plan every fork up front (zero mid-run interruptions), diagnose failures structurally before retrying, and escalate to the operator only when something is genuinely out of scope. Five concrete capabilities — persistent state, plan
