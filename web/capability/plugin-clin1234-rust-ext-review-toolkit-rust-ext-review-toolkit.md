# Rust Ext Review Toolkit

> 13 specialized agents and 4 commands for analyzing PyO3 Rust extensions. Tree-sitter-rust scripts detect unsafe-block soundness violations, panics crossing the FFI boundary, swallowed PyResults, [pyclass] Send/Sync gaps, missing traverse/clear, and PyO3 version-migration debt. Includes a 'migrate' command for the Bound-API and free-threading migration checklist.
