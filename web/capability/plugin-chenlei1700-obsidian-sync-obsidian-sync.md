# Obsidian Sync

> A Claude Code plugin that syncs project documentation to your Obsidian vault — one command, zero config. The Problem: You clone repos. Each has scattered documentation — .md files, .pdf references — buried in nested directories. You want to read and search them in one place, but they live across dozens of project folders. obsidian-sync moves all project documentation into your Obsidian vault with a single command, keeping them browsable both in Obsidian and in the original project.
