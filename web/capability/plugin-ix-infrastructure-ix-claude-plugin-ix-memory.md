# Ix Memory

> Ix Memory connects Claude Code to Ix, a structured, persistent memory backend for codebases. Instead of reading raw source files to answer questions about your code, Claude queries a live knowledge graph — dramatically reducing token usage, improving accuracy, and enabling reasoning that scales to large, complex projects. All analysis runs locally on your machine. No source code is ever transmitted to external servers.
