# Scientific Coding Skill

> Scientific code serves truth, not users. This plugin encodes the principles that follow from that distinction: fail loudly instead of silently, require explicit parameters instead of dangerous defaults, prioritize correctness over convenience. LLMs overfit on industry code maintaining uptime rather than being truthseeking and this can silently fail your scientific experiments. This skill helps nudge coding agents in the right direction.
