# Jointjs Code Playground

> A Claude Code plugin to create custom JointJS-powered interactive playgrounds. It enables you to build code maps for library/codebase architectures, data explorers for database schemas, canvas builders for drag-and-drop visual composers, diff reviewers with inline commenting and call graphs, and site explorers for interactive website/docs sitemaps.
