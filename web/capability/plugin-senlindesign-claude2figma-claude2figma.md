# Claude2figma

> A Design System compliance harness for Claude Code + Figma. Instead of generating hardcoded values, it enforces library-first component lookup, binds all visual properties (colors, typography, spacing, radius) to your existing design tokens and variables, and runs automated QA after every write. Works best with teams that have an established Figma Design System.
