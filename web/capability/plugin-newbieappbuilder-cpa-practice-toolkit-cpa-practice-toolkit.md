# Cpa Practice Toolkit

> A Claude Cowork plugin for solo CPAs and small accounting firms. Automates the most time-consuming administrative tasks in tax practice: client document checklists, engagement letters, missing docs follow-ups, return status emails, LLC monthly P&L summaries, and engagement termination letters. Fully bilingual in English and Spanish. Built by a licensed CPA based on real tax practice workflows. Works for any US state. IRC §7216 compliant engagement letter language included.
