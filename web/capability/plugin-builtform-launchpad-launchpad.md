# Launchpad

> The most comprehensive agentic coding harness for Claude Code that works for both greenfield and brownfield projects. Drops 38 slash commands, 36 sub-agents, and 16 skills into any repo to give Claude Code full project context, run it through structured shape → plan → build → review → ship loops, and enforce multi-agent quality gates before any change reaches main. Works in any existing TypeScript, Python, Go, Django, or polyglot repo — install the plugin and run /lp-kickoff to start.
