# Testing

> Kobiton brings agentic AI to mobile quality so engineers & testers can initiate testing directly from where code is built. With our Claude Code plugin, you can initiate Appium tests and inspect results on real devices without leaving your development workflow. You can manage test execution, save apps for future testing, review test execution results, work with a range of different real devices.
