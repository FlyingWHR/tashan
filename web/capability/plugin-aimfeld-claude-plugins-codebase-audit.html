codebase-audit

plugin:aimfeld/claude-plugins/codebase-audit · plugin

Produces a thorough, evidence-based software quality assessment of any git repository. Grades 16 dimensions — architecture, security, database design, observability, testing, disaster recovery, GDPR, dependencies, frontend bundle, and CI/CD speed — with file:line citations so every finding is verifiable in under a minute. Works on any language (Python, TypeScript, Go, Rust, Java, Ruby, PHP, C, etc.).

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
