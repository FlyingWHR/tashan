# Apiiro

> The Apiiro plugin for Claude Code connects developers directly to Apiiro’s Software and Risk Graph along with organizational context, bringing repository intelligence, ownership, architecture, policies, and risk insights into the development workflow. With Apiiro, developers can enrich prompts with relevant security and organizational context, get remediation guidance tailored to their codebase and internal policies, scan code changes for vulnerabilities before committing, generate threat model
