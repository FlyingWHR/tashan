co2-tracker

plugin:gwittebolle/claude-carbon/co2-tracker · plugin

Track the carbon footprint of your Claude Code sessions. Adds a live CO2 estimate to the status line, persists sessions to a local SQLite database, and generates shareable PNG report cards. Based on peer-reviewed emission factors from Jegham et al. 2025.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
