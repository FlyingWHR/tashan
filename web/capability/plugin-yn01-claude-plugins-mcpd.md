# Mcpd

> Diagnose MCP server configuration, connectivity, and available tools — all in one command. mcpd reads your global and project-level MCP config files, checks that required environment variables are set, verifies server connectivity (stdio and SSE/HTTP), and lists all available tools. Get a clear picture of your entire MCP setup in seconds.
