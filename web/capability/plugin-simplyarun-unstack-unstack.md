# Unstack

> Analyzes any website's technology stack from a single URL using only public signals. Runs a five-phase investigation (HTTP headers, HTML source, cookies, asset URL patterns, framework path probing) against 100+ detection signatures, then produces either a styled HTML report or a quick chat summary. Every technology identified is backed by specific evidence (the exact header, cookie format, or URL pattern that revealed it), not guesses. No API keys, no headless browser, no external dependencies.
