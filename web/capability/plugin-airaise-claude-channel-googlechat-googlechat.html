googlechat

plugin:airaise/claude-channel-googlechat/googlechat · plugin ✓ Google · official

A channel plugin that connects Google Chat to Claude Code via Google Cloud Pub/Sub. Send messages from Google Chat and receive replies from Claude Code — all through a familiar chat interface. Features sender gating with allowlist and pairing flow for security. Supports Workspace Events API, Workspace Add-ons, and traditional Cloud Function message formats.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
