# Daily Journal

> Plugin description: Conversational daily journaling for Obsidian vaults. Interviews you about your day, detects your emotional altitude using a 34-floor framework (from survival-mode lows to flow-state highs), tracks habits (gym, sleep, meditation), and saves structured markdown entries with YAML frontmatter. Optional advisory panel adds 1-2 sentences of pushback from named advisors. Works with any Obsidian vault.
