# Claude Cognis

> Persistent memory for Claude Code powered by Cognis. Automatically loads relevant context at the start of every session and saves session summaries when you stop — so Claude remembers what you've been working on across sessions. Supports personal memory (private to you) and team memory (shared across your repo). Includes semantic search, codebase indexing, and smart context assembly via MCP tools, skills, and hooks.
