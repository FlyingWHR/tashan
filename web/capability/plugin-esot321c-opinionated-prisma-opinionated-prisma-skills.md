# Opinionated Prisma Skills

> Opinionated skill plugin for Prisma ORM on self-hosted PostgreSQL. Enforces consistent decisions across schema design, migration safety, indexing, transactions, and the raw SQL boundary. Covers UUID v7, snakecase mapping, foreign key indexes, three-step safe migrations, concurrent index creation, and transaction patterns. Skills activate automatically based on context. Supports Claude Code, Codex CLI, Gemini CLI, Cursor, and OpenCode.
