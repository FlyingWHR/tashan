Orchestrator

plugin

Generate ready-to-paste Claude Code prompts with the right agent, orchestration pattern, and safety rails. Orchestrator synthesises patterns from 6 open-source projects into a single skill — 9 orchestration patterns, 15-domain agent selection, loop safety with circuit breakers, swarm coordination (hierarchical and mesh), multi-model consensus review, and sentinel quality gates. Describe a task, get an optimal prompt you can copy-paste into Claude Code.

Works with: Claude Code (native)
native: this artifact type is that client's own format
