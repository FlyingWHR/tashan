# Mtw E2e Runner

> JSON-driven E2E browser test runner — no JavaScript test files needed. Define tests as JSON action arrays and run them in parallel against a Chrome pool (browserless/chrome). Includes 3 specialized agents (test-creator, test-analyzer, test-improver), 4 slash commands (/run, /create-test, /verify-issue, /capture), and 16 MCP tools for the full test lifecycle. Features 28+ built-in actions, AI-powered visual verification, network request debugging, flaky test detection with stability learning, reu
