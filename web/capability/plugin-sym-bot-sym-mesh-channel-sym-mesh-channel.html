sym-mesh-channel

plugin:sym-bot/sym-mesh-channel/sym-mesh-channel · plugin

Real-time Claude-to-Claude mesh communication. Turns Claude Code into a peer node on the SYM mesh — two sessions on the same wifi discover each other via Bonjour and exchange structured cognitive signals as channel notifications. Each peer has its own Ed25519 identity, SVAF content gating, and local memory. Supports LAN (Bonjour, zero config) and cross-network (WebSocket relay). Built on the Mesh Memory Protocol (MMP), an open peer-to-peer protocol for multi-agent collective intelligence.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
