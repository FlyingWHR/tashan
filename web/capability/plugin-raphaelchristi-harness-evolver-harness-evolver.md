# Harness Evolver

> Autonomous LLM agent optimization using LangSmith. Spawns 5 parallel proposers in git worktrees, evaluates candidates via LangSmith experiments, and merges winners automatically. Includes evaluator agent (LLM-as-judge via langsmith-cli), critic, architect, and testgen agents. No external API keys needed beyond LangSmith.
