# Vibe Lingual

> Localize your app's UI without corrupting its logic. Scans every user-facing string by kind — JSX text, placeholder, aria-label, title, alt, toast, locale-sensitive date — and emits a six-block readiness brief; audits the stack for the gotchas that bite i18n retrofits (firebase-admin in SSR, structural-vs-presentational Intl, the timeZone decision, RTL surfaces, dynamic-route guard globs); then runs a confidence-routed extract - wire - translate - guard loop that mutates only with per-file ba
