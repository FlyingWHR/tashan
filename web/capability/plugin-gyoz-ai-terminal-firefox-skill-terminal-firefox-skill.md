# Terminal Firefox Skill

> Full Firefox browser in your terminal for Claude Code. Launches Browsh (a terminal Firefox renderer) in a tmux split pane and controls it via Marionette protocol. Includes a one-time Firefox patch that removes the hardcoded single-session limit on Marionette, allowing the control script to create session 2 alongside Browsh. Full command set: nav, eval, click, type, html, shot, title, url, back, forward, refresh, windows. Based on the actively maintained Browsh project.
