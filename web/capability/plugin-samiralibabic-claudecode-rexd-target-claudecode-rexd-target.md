# Claudecode Rexd Target

> Claude Code plugin for working with configured remote machines through REXD over SSH stdio. It adds target switching, remote filesystem tools, remote command execution, search, patch/edit support, and PTY sessions through a bundled MCP server. When a target is active, the plugin blocks Claude Code’s local filesystem/search/shell built-ins and directs Claude to the remote REXD tools instead.
