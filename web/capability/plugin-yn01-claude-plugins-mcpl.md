# Mcpl

> Tail and display MCP server stderr logs in real time. mcpl monitors log files for all configured MCP servers or a specific server, streaming output with timestamps, server name prefixes, and log-level icons (❌ ERROR, ⚠️ WARN, ℹ️ INFO). Run without arguments to watch all servers at once, or use --server to focus on one.
