# Adaptlypost

> Post and schedule social media content to 9 platforms — Instagram, TikTok, YouTube, X, LinkedIn, Facebook, Pinterest, Threads, and Bluesky — from Claude Code. Key features: - Cross-post to multiple platforms in a single command, with per-platform caption overrides for X length limits, LinkedIn formatting, etc. - Schedule posts to any future time, or bulk schedule up to 100 posts at once - Draft → review → publish workflow so Claude saves drafts you can approve before they go live - Per-platform
