# Teamcity CLI

> Interact with TeamCity CI/CD servers through Claude Code. Diagnose build failures, start and monitor builds, manage agents and queues, and access the TeamCity REST API — all through natural language. Claude learns TeamCity CLI commands, flags, and workflows so you can stay in your editor while it handles CI/CD operations.
