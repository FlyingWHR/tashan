genshijin

plugin:interfacex-co-jp/genshijin/genshijin · plugin

Ultra-compressed Japanese communication mode for Claude Code. Reduces output tokens by ~75% by eliminating keigo (polite language), filler phrases, and redundant particles while preserving full technical accuracy. Japanese-optimized fork of caveman with 3 intensity levels (丁寧/通常/極限). Safety valve auto-restores normal Japanese for destructive operations.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
