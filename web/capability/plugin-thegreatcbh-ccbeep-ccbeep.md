# Ccbeep

> Sound notifications for Claude Code. Plays distinct system sounds when tasks complete or fail, so you don't need to watch the terminal. Zero dependencies — uses only built-in OS tools (afplay on macOS, paplay on Linux, PowerShell on Windows). Features one-command install, interactive sound picker, timed mute, and per-event sound customization via config file.
