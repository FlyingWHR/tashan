# YouTube Transcriber

> Transcribe YouTube videos and playlists using browser-based caption extraction. Works with any video that has auto-generated or manual captions — no API key, no external service, zero configuration. Supports single videos and full playlists in any language. Outputs timestamped transcripts ready for further processing.
