# Mcpa

> Add stdio MCP servers to Claude Code interactively or with arguments. mcpa is a wrapper around claude mcp add that guides you through server name, command, args, env vars, and scope. Supports both direct mode (with arguments) and interactive mode (step-by-step prompts). Choose user scope to make a server available globally, or project scope to commit it to the repository.
