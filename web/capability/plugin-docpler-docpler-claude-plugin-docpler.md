# Docpler

> Convert Korean HWP (한글 워드프로세서) documents to Markdown. HWP is the most widely used document format in South Korea, commonly found in government, legal, and academic documents. This plugin provides a high-performance Rust-based CLI to convert HWP 5.0 files to Markdown directly within Claude Code. This product was developed with reference to the HWP document file (.hwp) specification published by Hancom (https://www.hancom.com/etc/hwpDownload.do).
