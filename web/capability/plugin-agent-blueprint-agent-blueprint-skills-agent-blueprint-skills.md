# Agent Blueprint Skills

> Open-source AI agent skills for enterprise deployment. (2) Vendor-agnostic agent deployment methodology with phased rollout, pilot-first approach, and test gates. (3) Multi-tool research agent with automatic depth routing from free to paid tools. Works with Claude Code, OpenAI Codex, and any coding agent via the Agent Skills open standard.
