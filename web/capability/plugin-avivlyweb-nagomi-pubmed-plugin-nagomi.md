# Nagomi

> Forensic-grade PubMed research engine for Claude Code. Search 36M+ biomedical articles with PICO-structured queries, synthesize evidence with GRADE confidence ratings, critically appraise article trustworthiness using Oxford CEBM hierarchy, verify citation accuracy against PubMed records, and export references in APA/Vancouver/BibTeX. Includes a research-assistant agent for comprehensive literature reviews. No API key required — queries PubMed E-utilities directly.
