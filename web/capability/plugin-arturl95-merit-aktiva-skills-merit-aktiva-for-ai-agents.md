# Merit Aktiva For AI Agents

> Connect Claude and other AI agents to Merit Aktiva — Estonia's most-used accounting software — and let them handle real bookkeeping safely. Six Claude Code skills that teach Claude the official Merit Aktiva REST API (HMAC-SHA256 signing, sales invoices, purchase invoices, payments, GL, bank statement import) and the 2026 Estonian tax rules (VAT 24/13/9, distributed-profit CIT 22/78, payroll, KMD codes, fringe benefits, board-member fees). Bilingual README in English and Estonian. Every write
