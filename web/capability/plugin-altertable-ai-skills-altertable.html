Altertable gives Claude governed access to your Altertable workspace so it can explore data, query the lakehouse, analyze product and business metrics, and help turn raw data into insights. The plugin bundles Altertable-specific Agent Skills with the Altertable MCP, allowing Claude to inspect schemas, write and run SQL, analyze funnels, build segments, interpret charts, forecast time series, configure monitoring agents, manage discoveries, and use memory for richer follow-up analysis.
