# Dotsecenv

> Manage GPG-encrypted environment secrets from Claude Code - a secure alternative to plaintext .env files. Store, retrieve, share, and revoke secrets in dotsecenv vaults where values are encrypted at rest with AES-256-GCM and access-controlled per GPG identity. Interprets .secenv files (the encrypted counterpart to .env), resolves references, and automatically detects GPG pinentry compatibility.
