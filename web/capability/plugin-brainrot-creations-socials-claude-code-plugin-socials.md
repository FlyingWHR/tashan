# Socials

> Official Claude Code plugin for Socials (Brainrot Creations). Ships an MCP server that connects Claude to the Socials browser extension so Claude can work with your logged-in sessions on X, LinkedIn, and Reddit. Claude talks to the extension over a local stdio MCP process and a localhost WebSocket (127.0.0.1:9847); the extension must have Agent Mode enabled.
