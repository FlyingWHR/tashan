# Learning Tutor

> AI-powered personal tutor plugin for Claude Code. Features adaptive teaching with 3 styles (progressive, Socratic, structured), pre/post testing with generative questions, spaced repetition across sessions, persistent learner profiles with proficiency tracking (levels 1-5), and teaching guardrails (hard stops, anti-rationalization). Supports bilingual teaching (Chinese/English).
