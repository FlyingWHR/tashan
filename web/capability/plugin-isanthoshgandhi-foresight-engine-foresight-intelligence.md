# Foresight Intelligence

> Strategic foresight intelligence using IFTF methodology. Two prediction modes: Soft Predict Future (Claude-native skill, instant, claude.ai + Claude Code) and Hard Predict Future (deterministic 12-step pipeline, Python-computed — Claude Code only). Both output four independent futures (Probable/Plausible/Possible/Preferable) with per-stakeholder conditional analysis. Try: Will India become the global AI leader? Will OpenAI or Anthropic win?
