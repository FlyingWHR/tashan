kindex

plugin:jmcentire/kindex/kindex · plugin

Kindex is a persistent knowledge graph for Claude Code. It turns Claude from a session-scoped tool into a project-scoped collaborator — capturing decisions, constraints, and context that survive across sessions, projects, and context resets. Memory plugins remember what happened. Kindex captures what it means and how it connects. Session 10 is as informed as session 1.
