# Gist Design

> Generates .gist.design files through guided conversation. Asks questions about your product's design decisions, interaction models, positioning, and boundaries, then writes a structured markdown file that AI coding tools (Cursor, Claude Code, Windsurf) and LLMs (ChatGPT, Claude, Perplexity) can read to understand your product accurately instead of guessing. Three modes: /gist-design create (full guided conversation), /gist-design quick (2-3 turn generation), /gist-design audit (scores how
