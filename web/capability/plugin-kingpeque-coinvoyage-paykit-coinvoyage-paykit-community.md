# Coinvoyage Paykit Community

> Accept any crypto payments (Bitcoin, Solana, Ethereum, Base, Arbitrum, Optimism, Polygon, BSC, Sui, plus stablecoins like USDC/USDT) in any Claude-built app via CoinVoyage. Bundles a skill that triggers on crypto checkout / payment gateway work, plus an MCP server with 15 tools for creating and managing PayOrders, webhooks, and cross-chain swaps. Non-custodial — funds settle directly to the merchant's wallet.
