the-genie-method

plugin:jackatzmon/genie-method/the-genie-method · plugin

A 3-step pipeline for non-technical professionals to build complete apps and write full-length books with AI. Includes two skills: spec-to-scripts (app building via interview, technical spec, and module-by-module Claude Code scripts) and write-to-publish (book/document writing via interview, story bible, and chapter-by-chapter writing scripts with consistency checks). Written by a medical professional for doctors, lawyers, plumbers, trainers, and anyone who isn't a developer.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
