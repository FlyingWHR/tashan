# Claude Telemetry

> Customizable multi-line status line for Claude Code — real-time session telemetry in your terminal. Shows remaining context window, rate limit countdown, git status, session duration, cost tracking, and more. Supports preset modes (compact/normal/detailed), 4 languages (en/ko/ja/zh), color-coded thresholds, and progress bars. Single Go binary with sub-10ms rendering.
