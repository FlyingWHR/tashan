codedna

plugin:larens94/codedna/codedna · plugin

CodeDNA makes any codebase AI-navigable by embedding architectural context directly in source files. One command annotates every file with exports:, usedby:, and rules: — so Claude always knows what a file provides, who depends on it, and what constraints must never be violated. No API key required. Uses your existing Claude subscription. Supports Python, TypeScript, JavaScript, Go, Rust, Java, and Ruby.

Works with: Claude Code, Cursor, Claude Desktop, Codex CLI, Gemini CLI, Cline, Windsurf, VS Code
