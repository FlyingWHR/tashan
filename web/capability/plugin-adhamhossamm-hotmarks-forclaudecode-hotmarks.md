# Hotmarks

> Semantic formatting plugin that gives your prompts weight. Type bold to mark non-negotiable directives — Claude must follow them exactly. Type underline to mark critical emphasis — Claude prioritizes them above everything else. A prompt-submit hook automatically detects markers, skips code blocks, and injects structured semantic context. Three modes (reminder, transform, both), configurable via .hotmarks file, zero runtime dependencies.
