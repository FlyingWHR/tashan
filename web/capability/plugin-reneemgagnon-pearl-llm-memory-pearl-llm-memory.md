# Pearl LLM Memory

> Externalized Cognitive State Transfer PEARL-LLM Memory (.pearl) is a JSON-based file format for storing structured, layered, verifiable context that persists across agent sessions. It gives autonomous agents a durable memory with immutable history, temperature-graded recall, cryptographic chain of custody, and branching decision trails. The format is agent-agnostic. The reference implementation is a zero-dependency Python CLI. Both are open.
