# Cmux Ultimate

> Complete cmux integration for Claude Code. Includes full CLI reference (~130 commands), browser automation (~40 subcommands with element refs), multi-agent orchestration patterns, sidebar metadata, lifecycle hooks (auto workspace naming, active/idle status, completion notifications), and two slash commands (/cmux:status, /cmux:open-browser). Built by combining the best features from four existing cmux plugins into one cohesive package.
