# Clawket

> LLM-native work management plugin for Claude Code. 10 lifecycle hooks auto-track your entire workflow — PreToolUse blocks code changes unless a task is registered. Includes 6 dashboard views (Kanban, Timeline, Wiki, Backlog, Plans, Summary), sub-agent task binding, and auto-cascade completion. All data stored locally in SQLite.
