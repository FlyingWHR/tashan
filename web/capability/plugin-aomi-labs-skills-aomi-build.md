# Aomi Build

> Use this to build agents hosted by Aomi Labs. An Aomi app is a platform-specific Rust API client compiled into an agentic application and loaded into the Aomi runtime to form a working crypto-trading agent. Apps are designed for crypto trading: the runtime supports native on-chain actions, so apps typically wrap complementary off-chain APIs from crypto platforms — CEXes, DEX aggregators, prediction markets, perp venues, oracles, social, on-chain analytics — to round out the agent's capabilities.
