# Devrunway

> Modular SDLC plugin for any tech stack. Run /setup to declare your tools (frontend, backend, DB, auth, CI, etc.), and devrunway installs only the matching standards, pre-wires MCP servers, and activates a runtime of 35 hooks that block secrets, enforce conventional commits, and catch SQL injection, XSS, PII-in-logs, and more on every save.
