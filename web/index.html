#4  Rank

Kept, current, used

Maintainer count, release cadence, deprecation and registry status; days since the last publish, push or release; npm downloads and public config reach as the gate.

Instruction depth is graded separately and never folded in. “Well kept” and “well documented” are different questions.

#5  Read

Somebody opened the docs

Per-tool documentation, two worked examples, setup and auth, a stated limitation. All four, or it is not deep. That is a read of the documentation, never of the running code.

#6  Prove

Every number, sourced

No black box. Each signal points back at where it came from: the MCP registry, npm, git history, OSV. If you don’t believe a number, go and check it.
