Why trust this

Not a directory. A measurement.

No stars, no listings

GitHub stars measure hype; download counts measure curiosity. We measure whether people actually wire it into their config — and keep it there.

No pay-to-rank, ever

Rank is a function of measured evidence, not spend. There is no promoted slot, no boost, no advertising in the Index.

Reproducible & open

Every signal is defined and re-derivable from public GitHub. If you don't believe a number, you can check it.
