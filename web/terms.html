What tashan is

tashan is a measurement of publicly available evidence about AI capabilities — MCP servers and agent skills. Every score is derived from public sources, and every signal on a capability page links to the source it came from. See the methodology.

What the audit covers, and what it does not. We check every npm-published capability against OSV for advisories affecting the version you would install today, flag scripts that execute at install time, read build provenance, and derive permission surface from declared dependencies. We do not review source code, execute the capability, or test its outputs for prompt injection. A clean audit means nothing known is wrong — not that nothing is wrong. You remain responsible for what you install.

The free tier

The Index, every score, the badges, the agent endpoints and the CLI are free, with no account and no quota. We may rate-limit abusive traffic, but we will not put a score behind a paywall. The data is provided as is, without warranty of accuracy, completeness or fitness for any purpose.
