You're in.

Two steps and doctor starts telling you what to do about what it finds.

1 · Copy your licence key

It was emailed to you, and it is always in your account.

2 · Activate it, once

npx tashan-cli activate tashan_…
npx tashan-cli doctor

activate checks the key and stores it in ~/.config/tashan/key. That is once per machine — not once per shell, and nothing to add to your shell profile. Every doctor run after it prints Pro · licence active, so you can always see it is on.

On another machine

Run npx tashan-cli activate there with the same key. Each machine registers as its own device — named after its hostname — so your account shows exactly what is activated. On a machine you are done with, npx tashan-cli activate --forget hands the slot back.

Your account

Your plan, renewal date, machines, licence key and invoices. tashan account opens it already signed in from any machine holding your key.

What changed

Free doctor named every finding — how many advisories, whether something runs a script at install, what it can reach. It still does, for everyone, permanently. With the licence it also gives you the part you act on: which advisory and the version that fixes it, what the install script runs, the full permission list, and the replacement to move to. Every run prints Pro · licence active, so you never wonder if it took.

Nothing about your config is uploaded. The CLI reads your local files and asks us only about capability names. That was true before you paid and it is true now.
