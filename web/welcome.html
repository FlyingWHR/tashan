Welcome to tashan Pro

You're in.

One command and every machine you work on is signed in. There is no key to copy and nothing to add to your shell profile.

npx tashan-cli login

It prints a short code and opens your browser. Approve the code, and the terminal has it — the same flow as gh auth login. Repeat it on any other machine; approving takes one click because this browser stays signed in.

Then

npx tashan-cli doctor

Reads your Claude Code, Cursor and Desktop configs and tells you what to do about what it finds. Nothing about your config is uploaded — the CLI reads local files and asks us only about capability names. That was true before you paid and it is true now.

What the licence changed

Free doctor named every finding: how many advisories, whether something runs a script at install, what it can reach. It still does, for everyone, permanently. With the licence it also gives you the part you act on — which advisory and the version that fixes it, what the install script runs, the full permission list, and the replacement to move to. Every run prints Pro · licence active, so you never wonder if it took.

Your account

Your plan, renewal date, machines and invoices live at your account — reachable from the account icon in the header on every page, any time, from any machine that is signed in.
