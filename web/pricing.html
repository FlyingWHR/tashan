How many tokens could you save?

CLI 0.3.0

Paste one JSON result from a tool you use. The counter runs on your device.

Use it with your agent

In one local MCP server’s settings, put tashan wrap -- before its usual command and reconnect. For example, node server.js becomes tashan wrap -- node server.js. Use --table before the separator if your agent accepts rows and columns.

tashan daily

Free shows how many tokens you could remove. With Pro, the same connection returns the smaller result automatically. The daily report counts tokens removed from tool text using o200k_base.

Try the same comparison in your terminal

Download the example, then run this command.

tashan tokens results.json --table
# with Pro: add --emit to export

How do I start?

After checkout, run npx tashan-cli login and approve the code in your browser. In CI, use your licence key.

Where do I manage billing?

Open your account for invoices, devices or cancellation.
